## 一、阶段一在毕设中的位置

我的毕设题目是《基于条件扩散模型的 NGSO 星座星地信道生成建模及与 CGAN 的对比研究》，承接学长论文的建议：在相同数据集和相同评价指标下，用扩散模型替换 CGAN 做公平对比。

整个毕设分 7 个阶段：

```
阶段0 环境+精读 → 【阶段1 数据层✅】→ 阶段2 指标库 → 阶段3 CGAN → 阶段4 扩散模型 → 阶段5 对比 → 阶段6 加分
```

**阶段一是地基**——如果数据错了，后面两个模型全错。所以这一阶段我设了"论文原图 + 理论公式"双重验收关卡，花了 5 天把 Corazza 信道数据层做扎实。

## 二、五天做了什么

### Day 1：仰角参数化（9月18日）

- 按 Corazza 1994 原文 Table I 实现三个仰角多项式：K(α) 二次、μ(α) 三次、σ(α) 一次
- **关键勘误**：学长论文表 3-1 把 K0 印成 2.371，原文是 2.731。我查证了 Corazza 原文和学长图 3-1 的曲线像素，确认是笔误，代码以原文为准
- 解决了单位争议：K 是线性值（功率比）、μ 是奈培(Np)、σ 是 dB，三者用 h=ln(10)/20 桥接
- 验收 G1：K 从 1.69(20°) 升到 11.89(80°)，σ 从 3.5 dB 降到 0.5 dB，趋势正确

### Day 2：静态分布采样（9月19日）

- 实现 Rice 采样（E[R²]=1 归一化）、Lognormal 阴影采样、复合包络 r=R·S
- 实现理论 CDF 裁判：Marcum Q 函数（用非中心卡方分布等价）+ 换元数值积分
- 实现 log 域标准化 + 仰角归一化
- 验收 G2：4 个仰角 KS 全部 < 0.0013，PDF/CDF 与理论曲线目视重合
- 物理单调性验证：mean(r) 从 0.48(20°) 升到 0.98(80°)，深衰落概率从 0.618 降到 0.007

### Day 3：时序相关性（9月21日，本阶段难点）

- 实现 Jakes 谱着色高斯噪声：白噪声 → FFT → 乘 √S_jakes → IFFT，ACF 对 J₀(2πfdτ)
- 实现一阶 IIR 低通阴影：ACF 指数衰减到 e⁻¹
- 组合生成完整时序序列 r[n]=R[n]·S[n]
- 验收 G3：ACF RMSE=0.0048（<0.02）、LCR 最大误差 9.9%（<15%）
- 搞懂了贝塞尔函数 J₀ 和 Jakes 谱的关系：维纳-辛钦定理——Jakes 谱的逆傅里叶变换就是 J₀

### Day 4：数据集固化（9月22日）

- 生成 10000×1000 的训练集，仰角 [20,80] 均匀采样
- 全库统一标准化常量（mu_log/sigma_log 一次性估计，所有样本共用）
- 存 npz + meta.json（种子、参数、日期、标准化常量）
- 验收 G4：npz 40.1 MB float32、同种子字节级一致、元数据齐全

### Day 5：全量验收与文档收尾（9月23日）

- 写一键验收脚本 validate_phase1.py，G1~G4 共 13 项检查全 PASS
- 仰角分箱统计 + Spearman 单调性验证：Spearman=1.0000（>0.95）
- 生成 75° 参考样本（未参与训练的仰角，供泛化评估用）
- 写阶段笔记、勾选里程碑 M1

### 版本 B：8 分钟详版

> 各位老师好，我汇报一下毕设阶段一的工作。
>
> **课题背景**：我的题目是《基于条件扩散模型的 NGSO 星座星地信道生成建模及与 CGAN 的对比研究》。学长的毕业论文用 CGAN 做了星地信道生成，他在结论里建议后续可以引入扩散模型做对比。我这个课题就是承接这个建议，核心是"公平"——相同数据集、相同指标、相同训练预算下，系统比较两类生成模型。
>
> **为什么先做数据层**：信道生成是"垃圾进垃圾出"的活——如果训练数据的分布和时序结构不对，再好的模型也学不出正确的信道。所以阶段一我设了四道验收关卡 G1~G4，每道不过关不进入下一步。
>
> **Day 1 仰角参数化**：Corazza 模型用 K（莱斯因子）、μ（阴影均值）、σ（阴影标准差）三个参数描述信道，都是仰角的多项式。这里有两个关键问题：一是单位，K 是线性功率比、μ 是奈培、σ 是 dB，三者不能混用；二是学长论文表里 K0 印成了 2.371，我查了 Corazza 1994 原文是 2.731，而且学长自己的图 3-1 曲线也对应 2.731，确认是笔误。
>
> **Day 2 静态分布**：信道包络 r = R·S，R 是 Rice 快衰落、S 是 Lognormal 阴影。我实现了采样器，还用 Marcum Q 函数加数值积分做了理论 CDF 裁判。验收时 4 个仰角的 KS 统计量都小于 0.0013，说明分布和理论完全吻合。
>
> **Day 3 时序相关性**：这是本阶段最难的一天。真实信道不是独立点，而是连续起伏的时序。Rice 分量的多普勒相关结构用 Jakes 谱整形高斯噪声实现，它的自相关函数理论上是贝塞尔函数 J₀(2πfdτ)。阴影是慢变过程，用一阶 IIR 低通实现。我用 ACF 和 LCR（电平通过率）两个指标自检，都对得上理论。这里我搞懂了贝塞尔函数的物理意义——它是 Jakes 多普勒谱的逆傅里叶变换。
>
> **Day 4 数据集固化**：生成了 10000 条、每条 1000 点的训练集，仰角在 20 到 80 度均匀采样。标准化常量由全库统一估计，存进 npz 和 meta.json。同种子可以字节级复现，这是后续多种子对比实验的基础。
>
> **Day 5 收尾**：写了一键验收脚本，13 项检查全过。还验证了仰角到信号强度的物理单调性——Spearman 相关达到 1.0，低仰角深衰落概率 17.9%、高仰角只有 0.06%。
>
> **下一阶段**：先建三层评价指标库（L1 分布、L2 时序、L3 BER），然后复现学长的 CGAN 作为基线，再实现条件扩散模型。预计指标库 4 天、CGAN 1 周、扩散模型 2 周。
>
> 汇报完毕，请老师指导。

## 五、踩过的坑与收获

### 技术坑

1. **K0 勘误**：不能盲信论文表格，要交叉验证原文和图
2. **单位混淆**：K 线性/μ Np/σ dB，搞错一个采样公式全错
3. **频域滤波乘 √S 不是 S**：FFT 系数是幅度，功率是幅度平方
4. **Jakes 谱端点奇异**：f=±fd 时分母为零，要加 ε 正则
5. **IIR 系数推导**：a = exp(-1/(fs·tau_c))，正号会发散
6. **KS 样本数**：小样本统计噪声大，n=5000 时 KS≈0.013，要 20 万样本才能稳过 0.01
7. **全库统一标准化**：不能每条序列各自算均值方差，否则仰角间强度差异被抹掉

### 工程收获

1. **先小后大**：调试用 100 条，验证用 50 条，全量只生成一次
2. **理论裁判**：每个实现都要有理论公式做参照，不能只靠目视
3. **可复现性**：随机数消耗顺序固定，同种子字节级一致
4. **回归测试**：一键验收脚本，改底层代码后跑一遍就知道有没有搞坏上层
