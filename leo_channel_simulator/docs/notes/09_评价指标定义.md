## 1. 为什么要三层指标

"生成得像不像"不能只看一张 PDF 图。学长把指标分三层，我们沿用：

| 层次 | 回答的问题 | 指标 |
|---|---|---|
| L1 静态分布 | 某一瞬间幅值的概率分布对不对 | PDF L1、KS、Wasserstein、均值/标准差/偏度/峰度 |
| L2 时序特性 | 随时间起伏的"节奏"对不对（深衰落多频繁、每次多久） | ACF、LCR、AFD |
| L3 系统性能 | 拿去通信，误码率曲线对不对 | QPSK BER 及 RMSE |
| 附加：泛化 | 没训练过的仰角能不能生成 | KL、JS、Spearman |

**核心认知**：L1 全对，L2 仍可能全错（把样本点随机打乱，PDF 不变但 ACF/LCR 全毁）。这正是扩散模型最可能与 CGAN 拉开差距的地方，也是论文第3章学长自己的弱项（LCR RMSE 0.58~0.88）。

学长报告值（同量级参照，代码不可得，**不作为标准答案**）：KS 均值 0.0362、Wasserstein 0.0380、ACF RMSE 0.0198、LCR RMSE 0.7025、AFD RMSE 0.0034、BER RMSE 均值 0.1536、仰角-均值 Spearman 0.9980。

## 2. L1：静态分布指标

设两组样本：参考 r_ref（Corazza 大样本）、生成 r_gen（模型采样，论文中每仰角约 500 条 × 1000 点）。

### 2.1 PDF 的 L1 距离

```
L1 = ∫ | p_gen(r) − p_ref(r) | dr
```

实现：两组用**完全相同的 bins**（以参考样本 min/max 定边界）做归一化直方图，逐 bin 差的绝对值求和乘 bin 宽。不用核密度估计（KDE 带宽会引入额外主观参数）。

### 2.2 KS 距离（论文式 2-35）

```
KS = max_r | F_gen(r) − F_ref(r) |
```

经验 CDF 的最大竖直差。直接用 `scipy.stats.ks_2samp(r_gen, r_ref).statistic`。
特点：对两条 CDF 任何位置的偏差都敏感；论文报告全部仰角 KS < 0.07。

### 2.3 Wasserstein-1 距离（推土机距离）

把一条分布"搬运"成另一条的最小代价，对尾部差异比 KS 更细腻：

```python
scipy.stats.wasserstein_distance(r_gen, r_ref)
```

### 2.4 矩统计

均值、标准差、偏度 skewness（不对称性，深衰落拖尾使偏度为正）、峰度 kurtosis（尾部厚度）：`scipy.stats` 直接提供。比较时报告相对误差。

**阶段2 自测要求**：同一参考分布分两半互比，以上指标都应 ≈ 0；人为给一组样本加偏移/缩放后，指标必须明显变大。

## 3. L2：时序特性指标（门限统一定义）

门限不直接用绝对幅值，而用**归一化电平** ρ = r_th / r_rms（r_rms 为该序列 RMS 值），测试门限取 ρ ∈ {−10, −5, 0, 5, 10} dB 等，与论文设置对齐。

### 3.1 ACF 自相关函数（论文式 2-36/3-37）

论文此处有个**表述模糊**：2.6 节按复信道 h(t) 写定义，第3章训练/评价的却是包络序列 r(t)。本课题统一明确为：

```
                Σ_t (r[t]−r̄)(r[t+τ]−r̄)
R_rr(τ) = ─────────────────────────────────────
              Σ_t (r[t]−r̄)²
```

即**包络的归一化自相关**（零均值、除以零滞后能量，R(0)=1）。论文写作中明确说明这一选择。
实现：FFT 快速相关或直接循环；滞后点数 × 采样间隔 = 物理时延 τ（秒）。
打分：前若干滞后点上生成与参考 ACF 之差的 RMSE（论文 3.4.3 口径）。

### 3.2 LCR 电平通过率（论文式 2-38）

```
N_R(r_th) = 单位时间内包络"向下"穿过门限 r_th 的平均次数（次/秒）
```

实现要点：
1. 取符号序列 s[t] = (r[t] − r_th) > 0；
2. 找 True → False 的翻转点（向下穿越）计数；
3. 除以序列总时长（点数 / f_s）。

深衰落门限处 LCR 高，表示频繁掉进深衰落；我们 Day 3 还用 Rice LCR 闭式公式做生成器自检：

```
N_R(ρ) = √(2π(K+1)) · f_d · ρ · exp(−K − (K+1)ρ²) · I₀(2ρ√(K(K+1)))
```

（ρ 为相对本地 RMS 的归一化门限，f_d 为最大多普勒频移）

### 3.3 AFD 平均衰落持续时间（论文式 2-39）

```
AFD(r_th) = P(r < r_th) / LCR(r_th)
```

直觉：低于门限的总时间占比 ÷ 掉下去的次数 = 每次平均待多久。
实现：占比用 CDF（或直接计数），LCR 用 3.2 的计数结果，二者必须来自同一批序列。

## 4. L3：QPSK 误码率（论文式 2-40）

理论 AWGN 下 QPSK 误比特率：

```
P_b = ½ · erfc( √γ_b )
```

衰落信道下不能直接套公式，要**过一遍真实调制解调链路**：

1. 生成随机比特 → QPSK 映射为符号 s ∈ {(±1±j)/√2}；
2. 信道作用：接收 y = s · g + n，其中 g 由生成包络构造（g = r / √(E[r²])，做平均功率归一化），n 为复高斯噪声；
3. 按给定 Eb/N0 定噪声方差：σ_n² = 1/(2·10^(EbN0_dB/10))（复基带约定，写代码时在文档里固定一种推导）；
4. 判决：取 sign(Re y)、sign(Im y) 解出比特，与原比特比较；
5. Eb/N0 扫描 **0~34 dB、步长 2 dB**（与论文一致），每个点保证足够误码计数（误码数 < 100 时加大比特数或标注置信限）；
6. 每条包络序列对应一次 BER 曲线，多序列统计平均。

打分（论文式 3-4 口径）：

```
BER_RMSE = √( (1/N) · Σ_EbN0 [ log10 BER_gen − log10 BER_ref ]² )
```

在 **log10 域**算 RMSE（BER 跨好几个数量级，在线性域算会被高信噪比小点淹没）。
实现坑：BER = 0 时 log 无意义，统一加平滑下限（如 max(BER, 1/总比特数)），两模型处理方式一致。

## 5. 泛化指标（连续仰角）

- **KL 散度**：KL(p_gen ‖ p_ref) = Σ p log(p/q)，直方图 bins 相同并做 +ε 平滑防零；
- **JS 散度**：KL 的对称有界版本（0~ln2），更稳，作为主报告量；
- **Spearman 秩相关**：扫描仰角 20°~80°（含未训练的中间仰角如 75°），把"仰角序列"和"生成包络均值序列"做 `scipy.stats.spearmanr`，检验模型是否学到单调的仰角→分布映射（学长 0.9980）。

## 6. 工程实现统一规定（两模型公平性）

1. 所有指标封装在 `generative/metrics/{distribution,temporal,ber,generalization}.py`，阶段2冻结接口，之后只调不改；
2. 参考与生成的**样本数、序列长度、采样率、门限集合、bins 数**必须一致，作为函数入参显式传入；
3. 每个指标函数都接收 `rng`（需要重采样/补比特时用），保证多种子实验可复现；
4. 指标输出统一 dict 格式，方便阶段5汇总成表；
5. BER 测试比特数、平滑下限、Eb/N0 网格写进配置文件，不硬编码。
