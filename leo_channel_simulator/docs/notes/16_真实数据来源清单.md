## 二、P1：公开数据集检索

### 检索入口

- Zenodo：<https://zenodo.org/search?q=satellite%20fading%20envelope>
- IEEE DataPort：<https://ieee-dataport.org/>（站内搜索，部分数据集需免费注册）
- 补充：Mendeley Data <https://data.mendeley.com/>、NASA/ESA 开放数据门户

### 检索词（逐组尝试）

1. `satellite fading envelope`
2. `LEO satellite channel measurement`
3. `land mobile satellite channel measurements`（LMS 信道，经典方向）
4. `satellite beacon measurement time series`
5. `satellite received signal strength dataset`

### 期望数据形态

- 接收包络或接收功率的时间序列（CSV / .mat / .h5）
- **最好带仰角标注**（或附带过境时刻可反推仰角），环境标注（农村/城郊/城市）加分
- 采样率与时长需能支撑 LCR/AFD 等时序指标计算

### 筛选标准

- 有明确 DOI 与配套论文，可引用
- 频段与场景尽量贴近课题（S/C/Ku/Ka 星地链路）
- 授权允许学术研究使用

## 三、P2：SatNOGS IQ 录音

- 入口：<https://db.satnogs.org/>
- 内容：全球地面站网络上传的海量卫星过境 IQ 录音，含轨道元数据（可算仰角轨迹）
- 处理链路：IQ 录音 → 下变频/滤波 → 幅值包络 → 按仰角分段 → 与生成模型输出同格式对比
- 工作量提示：需写一段 IQ→包络的预处理脚本，适合有余力时做

## 五、P4：兜底方案

### Alphasat 信标

- ESA Alphasat Q/V 频段信标测量有公开论文，部分附带数据或可向作者申请（并入 P3 流程）

### 自采 SDR

- 硬件：RTL-SDR（约 200 元）或 USRP
- 目标信号：NOAA 气象卫星 APT 下行（137 MHz，过境频繁、信号强）
- 产出：自采包络序列 + 实际仰角轨迹，可做定性验证
- 仅在时间充裕时考虑，不阻塞主线

## 七、检索结果记录（2026-10-06 实搜）

### 结论：无现成"包络+仰角"数据集，三条可行路径收敛如下

**路径 A：AlphaSat Q/V 频段实测（质量最高，需邮件申请）**
- 线索：Al Homssi et al., *Deep Learning Forecasting and Statistical Modeling for Q/V-Band LEO Satellite Channels*, IEEE TMLCN 2023（DOI: 10.1109/TMLCN.2023.3286793），数据形态完美匹配：EPL 功率时间序列 + 仰角 + 雨率三通道
- 数据来源方：RMIT Al-Hourani 组（墨尔本）/ 意大利 Tor Vergata（Aldo Paraboni 载荷 PI 单位）
- 行动：按第四节邮件模板向 bhomssi@ieee.org 或 Tor Vergata 组申请

**路径 B：SatNOGS IQ 录音自行提取包络（完全公开，需写提取管线）**
- 实测存在：Zenodo 3941245 "BY70-2 UHF telemetry beacon IQ recording"（537 MB，436 MHz，192 ksps raw IQ，2020-07-12）
- SatNOGS DB（db.satnogs.org）有海量同类过境录音，带轨道元数据可反推仰角
- 行动：写 IQ→包络→按仰角分段 提取管线（约 1~2 天工作量）

**路径 C：3GPP TR 38.811 交叉验证（兜底，已集成）**

**已排除**：
- LENS（Zenodo 15331285/15331299）：Starlink 网络层 KPI（吞吐量/RTT/SNR @1Hz），无物理层包络，文件 39 GB 且分卷，不适用
- Tian & Cai [18]（arXiv:2603.24620）：无公开数据集，实测数据未开放
- CYGNSS：GNSS-R 遥感 DDM 数据，非星地通信信道

### 建议行动顺序

1. 发 AlphaSat 申请邮件（等待期间不阻塞）
2. 同时走路径 B：下载 BY70-2 录音试手，编写 IQ→包络提取脚本
3. 若 A 获批则以 A 为主验证数据，B 为补充；若 A 未果则 B + C 组合写入论文
