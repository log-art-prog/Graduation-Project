## Day 2：静态分布（i.i.d. 采样）

### Q2.1 Rice 采样公式
`sample_rice_iid` 里 `s_R = sqrt(1/(2*(K+1)))` 和 `m = sqrt(K/(K+1))`，这两个公式是怎么来的？联立的两个条件是什么？

> 提示：第 84-87 行注释写了——条件(1) K = m²/(2·s_R²)，条件(2) m² + 2·s_R² = 1

### Q2.2 为什么是两路 z
`sample_rice_iid` 生成了 `z = rng.standard_normal((2, n))`，为什么要两路？一路不行吗？

> 提示：复平面 = 实部(I) + 虚部(Q)，Rice 包络是复数到原点的距离

### Q2.3 Lognormal 的 exp
`sample_shadow_iid` 里 `S = np.exp(mu + H_DB_TO_NEPER * sigma * z)`，为什么要取 exp？不取会怎样？

> 提示：S 是信号增益，物理上必须 > 0；正态分布可以产生负数

### Q2.4 h 的作用
`H_DB_TO_NEPER = np.log(10.0) / 20.0`，这个 h 在公式里起什么作用？为什么是 ln(10)/20 而不是 ln(10)/10？

> 提示：sigma 是 dB（20·log₁₀），不是 dB（10·log₁₀）；幅度域 vs 功率域

### Q2.5 Marcum Q 的等价
`marcum_q1` 用 `ncx2.sf(b², df=2, nc=a²)` 实现，为什么非中心卡方分布能等价于 Marcum Q？

> 提示：Rice 包络的平方 = 非中心卡方变量（自由度2，非中心参数 = 直射分量功率）

### Q2.6 复合 CDF 的换元
`corazza_cdf_theory` 里做了换元 x = ln S，为什么？直接对 S 积分不行吗？

> 提示：lognormal 分布在 S 域有长尾，数值积分难收敛；换元后权重变成正态密度，对称好积

### Q2.7 标准化的 eps
`fit_standardizer` 里 `np.log(samples + eps)`，eps=1e-6。为什么需要 eps？不加会怎样？

> 提示：r 可以接近 0（深衰落），log(0) = -inf

### Q2.8 标准化的全局性
注释说"mu_log/sigma_log 必须由全训练集一次性估计"，为什么不能每条序列各自算自己的？

> 提示：如果每条各自标准化，模型学到的是"每条各自的形状"而不是信道分布

## Day 3：时序相关性（色噪声 + 序列生成）

### Q3.1 √S vs S（经典坑）
频域滤波时乘的是 `np.sqrt(S)` 而不是 `S`。为什么？乘 S 会发生什么？

> 提示：功率 = 幅度的平方；FFT 系数是幅度，不是功率

### Q3.2 fftfreq 的顺序
`np.fft.fftfreq(n, d=1.0/fs)` 返回的频率数组是按 `[0, 1, 2, ..., -n/2, ..., -1]` 排列的。为什么不直接用正频率 `linspace(0, fs, n)`？

> 提示：FFT 输出就是这个顺序，fftfreq 和它一一对应；手动排序会导致频率和谱错位

### Q3.3 端点奇异
Jakes 谱在 f=±f_d 处分母为零（发散到无穷）。代码怎么处理的？如果不处理会怎样？

> 提示：`np.maximum(1.0 - ratio**2, eps)`；不处理 → IFFT 输出 inf/NaN

### Q3.4 IFFT 后取 .real
`np.fft.ifft(W_filtered).real`，为什么要 `.real`？理论上输入是实信号的 FFT，IFFT 结果不应该就是实数吗？

> 提示：数值误差留下 ~1e-16 的虚部；不取会影响后续 mean/std

### Q3.5 归一化的必要性
`colored_gaussian_jakes` 和 `colored_gaussian_lp` 最后都有 `(x - x.mean()) / x.std(ddof=0)`。为什么必须加？

> 提示：Day 2 的 Rice 公式要求 z1,z2 ~ N(0,1)；频域/IIR 滤波后方差不正好是 1

### Q3.6 IIR 系数推导
`a = np.exp(-1.0 / (fs * tau_c))`，这个公式怎么推出来的？为什么是负号？正号会怎样？

> 提示：目标 a^(fs·tau_c) = e⁻¹；正号 → a>1 → IIR 不稳定 → 发散

### Q3.7 IIR 输出方差
一阶 IIR 对单位方差白噪声的输出方差 = (1-a)/(1+a)，不等于 1。这个公式怎么来的？不归一化会怎样？

> 提示：稳态方差 = (1-a)²·σ_w² / (1-a²) = (1-a)/(1+a)·σ_w²

### Q3.8 为什么要两路 Jakes
`generate_corazza_sequence` 里调了两次 `colored_gaussian_jakes`（x 和 y），为什么需要两路？

> 提示：Rice 包络是复数 |(m+s_R·x) + j·s_R·y| 的模；实部和虚部各需要一路

### Q3.9 阴影为什么用 IIR 而不用 FFT
Rice 分量的色噪声用频域 Jakes 谱滤波，阴影用一阶 IIR。为什么不统一用 FFT？

> 提示：阴影的理论 ACF 是指数衰减（一阶），Jakes 谱是贝塞尔衰减；IIR 天然产生指数 ACF

### Q3.10 ACF 用复过程不用包络
自检 ACF 时用 `z = x + 1j*y`（复过程），而不是 `R = |z|`（包络）。为什么？

> 提示：J₀(2πf_dτ) 是复基带过程的 ACF，不是包络的；包络 ACF 是另一个函数

### Q3.11 ACF 用 FFT 算要补零
`_acf_fft` 里 `n_fft = 1 << (2*n-1).bit_length()`，为什么要补零到 2n 以上？

> 提示：不补零 → 循环卷积（首尾相连）→ 大滞后处 ACF 偏差大

### Q3.12 过采样截断
ACF 自检时生成 2n 点取中间 n 点。为什么？

> 提示：频域滤波是循环卷积，序列两端互相污染；取中间段远离边界

### Q3.13 K=0 退化
ACF 自检用 K=0（纯 Rayleigh）。为什么不用 K>0？

> 提示：K>0 时有直流分量 m，复过程 z = (m + s_R·x) + j·s_R·y 的 ACF 会叠加直流项，不再是纯 J₀

### Q3.14 LCR 的物理含义
LCR（电平通过率）是什么物理量？它和 ACF 验证有什么不同？

> 提示：LCR = 单位时间内信号向下穿过某门限的次数；ACF 看"相邻点有多像"，LCR 看"信号起伏有多频繁"

### Q3.15 rng 串行取数
`generate_corazza_sequence` 里 x、y、g 三次调用都用同一个 rng，不新建。为什么？

> 提示：同一 rng 串行取数 → 三段随机数天然独立；如果各自新建 rng，可能重复

## 参考答案

### A1.1
- K：线性值（功率比，非 dB）
- μ：奈培(Np)，即 ln S 的均值
- σ：dB，即 20log₁₀(S) 的标准差
- μ 用 Np 而非 dB：因为采样公式 S = exp(μ + h·σ·z)，exp 的指数必须是无量纲的，μ 直接在 ln 域，不用转换。如果 μ 用 dB 还得额外转换。

### A1.2
学长表 3-1 印 2.371 是笔误。依据：Corazza 1994 原文 Table I 为 2.731，且学长自己的图 3-1 曲线像素提取也对应 2.731。代码注释第 14-15 行记录了勘误。

### A1.3
原始数据趋势不同：K 是曲线增长（需要二次），μ 有拐点（需要三次），σ 近似线性下降（一次就够）。统一用一次会拟合不好。多项式次数由实测数据决定，不是人为选的。

### A1.4
多项式是对 20°~80° 实测数据的经验拟合，不是物理定律。超出范围后可能剧烈偏离真实值（如 K 可能变负），导致后续采样公式出错。经验拟合禁止外推是基本准则。

### A1.5
代码不会报错，但结果全错。K=10dB 在线性域是 10^(10/10)=10，而代码直接当线性值用，K=10 会让 m=√(10/11)≈0.95，散射几乎为零。如果传 dB 必须先转换：K_lin = 10^(K_dB/10)。

### A2.1
两个条件：(1) K = m²/(2·s_R²)（莱斯因子定义：直射功率/散射功率）；(2) m² + 2·s_R² = 1（归一化 E[R²]=1）。联立解出 s_R 和 m。

### A2.2
一路不够。Rice 包络 R = √((m+s_R·z1)² + (s_R·z2)²) 是复平面上的点到原点的距离。实部需要一路 z1，虚部需要一路 z2。只有一路就退化为一维，不是 Rice 分布。

### A2.3
S 是信号增益（乘性因子），物理上必须 > 0。正态分布可以产生负数，取负的 S 没有物理意义。exp 保证 S > 0，且 ln 域正态 = 线性域对数正态（Lognormal 名字来源）。

### A2.4
h = ln(10)/20 把 σ 从 dB 换成奈培(Np)。用 /20 而不是 /10 是因为 σ 是幅度域（20·log₁₀），不是功率域（10·log₁₀）。20log₁₀(x) = ln(x)/h，所以 h = ln(10)/20。

### A2.5
Rice 包络 R 的平方 R² = (m+s_R·z1)² + (s_R·z2)²，这正是自由度 2、非中心参数 a²=m²/(s_R²)·... 的非中心卡方分布。Marcum Q₁(a,b) = P(R > b) = P(R² > b²) = ncx2.sf(b², df=2, nc=a²)。

### A2.6
lognormal 在 S 域有长尾（S 很大时概率密度衰减极慢），数值积分难收敛。换元 x=ln S 后，dS = S·dx = eˣ·dx，被积函数乘 S 后正好和正态密度抵消，剩下正态权重 × Rice CDF，对称且快速收敛。

### A2.7
r = R·S 可以接近 0（深衰落时 R 和 S 同时很小）。log(0) = -inf，会污染整个标准化结果。eps=1e-6 把 0 抬高到 1e-6，log 后是 -13.8，有限的。

### A2.8
如果每条序列各自算 mu_log/sigma_log，标准化后每条的均值都是 0、方差都是 1。模型看不到不同仰角下信号强度的差异——低仰角信号弱（r 小），高仰角信号强（r 大），这个物理规律会被抹掉。全库统一常量保留了仰角间的差异。

### A3.1
FFT 系数是频域的**幅度**（复数），功率 = |幅度|²。我们要输出功率谱 = S(f)，所以幅度要乘 √S（平方后 = S）。乘 S 的话输出功率谱 = S²，U 型碗形状变深，方差也不对。

### A3.2
`np.fft.fft` 输出的顺序就是 `[0, fs/n, ..., fs/2, -fs/2, ..., -fs/n]`（正频率在前半，负频率在后半）。`fftfreq` 返回的就是和它一一对应的频率。如果用 `linspace(0, fs, n)`，频率和 FFT bin 就错位了，乘 √S 后着色位置全错。

### A3.3
`np.maximum(1.0 - ratio**2, eps)` 把分母卡在至少 eps（1e-10）以上。不处理的话，f=±f_d 时 1-(f/fd)²=0，1/√0=inf，IFFT 后序列出现 NaN 或巨大尖峰。

### A3.4
理论上输入是实信号，FFT 满足共轭对称，IFFT 结果应该是纯实数。但浮点运算留下 ~1e-16 的虚部。不取 `.real` 的话，后续 `mean()` 和 `std()` 对复数运算，结果可能出错或报警告。

### A3.5
Day 2 的 Rice 公式 `R = √((m+s_R·z1)² + (s_R·z2)²)` 要求 z1,z2 ~ N(0,1)（标准正态）。频域滤波后方差受 eps、n、离散化影响，不正好是 1（可能 0.7 或 1.3）。不归一化 → s_R·z1 的方差变了 → E[R²]≠1 → Day 2 验过的分布就废了。归一化保证色噪声和白噪声在统计上可互换（都是 N(0,1)），只是多了时序相关。

### A3.6
目标：ACF 在 k=fs·tau_c 个采样点处降到 e⁻¹。一阶 IIR 的 ACF = a^k，所以 a^(fs·tau_c) = e⁻¹。两边取自然对数：(fs·tau_c)·ln(a) = -1 → ln(a) = -1/(fs·tau_c) → a = exp(-1/(fs·tau_c))。负号是数学推出来的。正号 → a>1 → IIR 递推中每步放大上一步 → 指数增长 → inf。

### A3.7
稳态方差 = (1-a)²·σ²_w / (1-a²) = (1-a)/(1+a)·σ²_w。当 a=0.9967（默认参数），方差 ≈ 0.00165，远小于 1。不归一化 → 阴影 S = exp(μ + h·σ·g) 的 g 方差太小 → S 几乎不变 → 看不出阴影慢变效果。

### A3.8
Rice 包络是复数 (m+s_R·x) + j·s_R·y 的模。实部需要一路色噪声 x，虚部需要一路 y。两路独立（同 rng 串行取数）。只有一路就退化为一维高斯，不是 Rice 分布。

### A3.9
阴影的理论 ACF 是指数衰减 R(k)=a^|k|（一阶系统的特征），IIR 天然产生指数 ACF。Jakes 谱的 ACF 是贝塞尔函数 J₀（振荡衰减）。两者形状完全不同，不能用 FFT+Jakes 谱来产生阴影。IIR 是指数 ACF 最简单直接的实现。

### A3.10
J₀(2πf_dτ) 是**复基带过程** z = x+jy 的自相关函数（Jakes 1974 证明）。包络 R = |z| 是对 z 取模（非线性变换），它的 ACF 是另一个函数（涉及超几何函数，没有简单闭式）。用 R 算 ACF 去和 J₀ 比 = 拿苹果和橘子比，对不上不是因为实现错了，而是比较对象错了。

### A3.11
不补零的话 `ifft(fft(x) * conj(fft(x)))` 算的是**循环自相关**——序列首尾相连卷积。当 k 接近 n 时，结果会把序列开头和结尾的样本混在一起。补零到 ≥2n 后变成**线性自相关**，首尾不互相干扰。

### A3.12
频域滤波法本质是循环卷积，序列首尾会"绕回来"互相污染。生成 2n 点取中间 n 点，中间段远离两端边界，循环卷积的污染最小。直接用 n 点的话，大滞后处 ACF 偏差大（实测 RMSE=0.0279 降不到 0.02；过采样后 0.0048）。

### A3.13
K>0 时复过程 z = (m + s_R·x) + j·s_R·y 里有直流分量 m。ACF = m² + s_R²·J₀(2πf_dτ)，多了一个常数项 m²，不再是纯 J₀。K=0 时 m=0，z = s_R·(x+jy)，ACF = s_R²·J₀(2πf_dτ)，纯 J₀，可以直接和理论比。

### A3.14
LCR = Level Crossing Rate = 单位时间内信号向下穿过某门限的次数（次/秒）。它衡量"信号起伏有多频繁"。ACF 衡量"相邻点有多像"（二阶统计），LCR 衡量"穿越门限的频率"（高阶统计）。两者从不同角度验证时序结构对了。

### A3.15
同一个 rng 串行取数：第一次调用消耗前 n 个随机数，第二次消耗接下来 n 个，第三次再接下来 n 个。三段天然不重叠 → 统计独立。如果各自新建 rng（相同种子），三次调用产生完全相同的随机数 → x=y=g → Rice 公式退化，阴影和快衰落相关，模型假设被破坏。

## Day 4 参考答案

### A4.1
标准化常量必须代表**整个数据集**的分布。边生成边算只能用部分数据，且每条样本用到的常量不一致——低仰角样本可能用前 100 条算的 mu_log，高仰角用前 5000 条算的。结果：不同仰角间的信号强度差异（低仰角弱、高仰角强）被标准化抹掉，模型学不到这个物理规律；且推理时没有唯一常量可用来反还原。

### A4.2
生成阶段要做 log、求均值方差等统计运算，float64 的精度（~1e-15）保证统计量稳定；float32 只有 ~1e-7，大批量统计会有累积误差。存储阶段 10000×1000 个数，float64 是 80MB，float32 是 40MB，省一半。转换损失 1e-7 量级，对神经网络训练完全无影响。全程 float32 "能跑"，但统计环节的精度白丢了。

### A4.3
随机数生成器是**有状态的**：每次 `rng.uniform(...)`、`rng.standard_normal(...)` 都消耗一段随机数流。同一 seed → 同一随机数流 → 只要消耗顺序固定，结果逐元素确定。"先仰角后序列"固定了消耗顺序，所以 seed=42 两次构建得到字节级相同的数据集（G4 同种子复现的根据）。调换顺序 = 同一随机数流被不同方式切分 = 不同的数据集，且仰角和序列的配对也变了。

### A4.4
json 模块只认 Python 原生类型：dict、list、str、int、float、bool、None。`data["mu_log"]` 是 np.float64（numpy 标量），不在清单里，直接 dump 抛 `TypeError: Object of type float64 is not JSON serializable`。`float(...)` 转成 Python 原生浮点即可。数组（np.ndarray）同理不能直接放 json。

### A4.5
`**data` 是 dict 解包：`savez(file, x_std=..., alpha_norm=..., ...)`。key 名成为 npz 压缩包内部的文件名，`np.load` 后 `z.files` 返回这些 key，靠名字取数组。所以 key 名就是数据集的"表结构"——build/save/load 三处必须用同一套名字，改一边漏一边就会 KeyError。

### A4.6
`self.x[idx]` 是一维 ndarray（shape (1000,)），`torch.from_numpy` 专门接受 ndarray 且零拷贝共享内存。`self.alpha[idx]` 是 numpy **标量**（0 维，np.float32 类型），`from_numpy` 不接受标量会 TypeError。所以先 `float(...)` 转 Python 标量，再用 `torch.tensor(...)` 包装。

### A4.7
复现性验证的是**机制**（同 seed → 同输出），机制与样本数无关，100 条几秒出结果；10000 条要几分钟，没必要每次验证都付这个成本。全量数据集只在最后生成一次存盘。这是"先小后大"调试策略的一部分。

### A4.8
隐患：该分支绕过 save_dataset，之后任何产出物缺失（meta.json、未来的字段）都不会被发现——脚本照样全绿。Day 4 的 meta.json 就是这么漏的：npz 在、meta 没生成，脚本 PASS，但 G4"元数据齐全"实际没达标。对策：加载分支里显式 `assert meta_path.exists()`，把 G4 的每一项都变成脚本强制检查而不是人工记忆。

### A4.9
每个 batch 重算常量 → 同一仰角的样本在不同 batch/epoch 被标准化成不同数值 → "标准正态到信道"的映射目标本身在漂移，生成器学不到稳定分布；仰角间的强度差异（低仰角 r 小、高仰角 r 大）被逐批抹掉，条件生成失去物理意义；推理时也没有唯一常量把生成结果还原成物理包络去算 BER。

### A4.10
mu_log/sigma_log 是 x_std 回到物理世界的唯一桥梁：`r = exp(x_std · sigma_log + mu_log)`（inverse_standardize）。评估、画图、算深衰落概率、算 BER 都需要物理量。丢了它 npz 里的数字就只是"无量纲数"，要么重算整个数据集，要么从 npz 里的 mu_log/sigma_log 数组恢复（我们恰好也存了数组，双保险）。

## Day 5 参考答案

### A5.1
分散脚本每次改动后要逐个跑 4 个脚本，容易漏。`validate_phase1.py` 把 G1~G4 串成一个出口，**一屏看完 PASS/FAIL**，本质是**回归测试**——以后阶段二改了底层代码（比如改了 corazza.py），跑一遍它就知道有没有把上层搞坏。它还是阶段一的"出口门禁"：退出码 0 才能进阶段二。

### A5.2
`corazza_cdf_theory` 内部用 `scipy.integrate.quad` 做数值积分，是**标量函数**，每次调用约几毫秒。20 万样本直接逐个积分 = 20 万次 quad = 几十分钟。取 200 个网格点算理论 CDF（200 次 quad，不到 1 秒），再 `np.interp` 插值回样本点，积分次数从 N 降到 200，速度提升两个数量级，且插值误差远小于统计噪声。

### A5.3
KS 统计量 D_n = max|F_emp - F_theory| 的渐近标准差约为 1/√n。n=5000 时 1/√5000≈0.014，所以即使实现完全正确，KS 也可能抖到 0.013；n=200000 时 1/√200000≈0.0022，统计噪声压到阈值以下。**阈值 0.01 是针对大样本设定的**，小样本过不了不是实现错了，是统计噪声太大。

### A5.4
用 `alpha_deg`（原始角度，20~80°）。原因：① bins 边界 `np.arange(20, 81, 10)` 是物理角度，和 alpha_deg 直接对应；② alpha_norm 是 [-1,1]，分箱边界要换算，语义容易混；③ 画图时 x 轴直接是物理仰角，读者一看就懂。

### A5.5
r₀ 取**全库 5% 分位数**（`np.quantile(r_all, 0.05)`）。不用固定值 0.5 的原因：不同仰角信号强度量级差异大（低仰角 mean≈0.59，高仰角 mean≈0.93），固定门限 0.5 在低仰角是"中位数附近"，在高仰角是"极深衰落"，没有可比性。用全库分位数保证"深衰落"的定义在所有仰角下一致——都是全库最弱的 5%。

### A5.6
Pearson 衡量**线性**相关（要求关系近似直线），Spearman 衡量**单调**相关（只要求一个升另一个也升，不管是不是直线）。物理上 Corazza 模型只保证"仰角越高平均包络越大"，这个关系是单调但非线性的（K 是二次多项式）。用 Pearson 可能因为非线性而偏低，用 Spearman 能正确反映单调性。目标 > 0.95，实测 1.0000。

### A5.7
训练集仰角是连续均匀采样，几乎不可能正好包含 75.0°（最接近的可能是 74.97° 或 75.03°）。75° 参考样本是**精确 75.0°** 的标准答案，供阶段四/五做"连续仰角泛化"评估时用——模型在训练时没见过 75.0°，生成的 75° 样本和参考样本对比，就能量化泛化能力。

### A5.8
参考样本和训练集必须**统计独立**。同一 seed 会导致随机数流重叠，75° 样本可能和训练集里某些样本共享随机数前缀，评估时就不是"独立参考"了。用不同 seed（2026 vs 42）保证随机数流完全不重叠，参考样本是真正独立的。

### A5.9
退出码 0 = 全部 PASS，1 = 有 FAIL。用退出码不只是打印的原因：① 自动化脚本/CI 可以根据退出码判断成败，不用解析文本；② 将来阶段二可以 `python validate_phase1.py && python train_cgan.py`，验收不过就不启动训练。这是 Unix 工具链的标准约定。

### A5.10
好处：① 每个 validate_gx 内部可以任意调 check，不用管 return 值，代码更简洁；② check 项数量灵活（G2 有 2 个仰角、G3 有 ACF+LCR 等），全局列表自动收集。风险：全局状态，如果同一个 check name 被调两次会重复计数；但本项目每项检查名唯一，风险可控。这是"收集器模式"的常见用法。

## Day 6 参考答案

### A6.1
`density=True` 后第 i 个 bin 的值是概率密度 p_i = n_i/(N·Δx)，直方图总面积 Σp_i·Δx = 1，与 PDF 的 ∫p dr=1 对齐。计数直方图的值是"样本个数"，两组做差单位是"样本数"，N 不同还不可比；且 ∫|p_gen−p_ref|dr 的黎曼和是 Σ|Δp_i|·**Δx**，漏掉乘 bin_width 得到的是"密度差之和"（量纲 1/r），不是无量纲的概率面积 L1。

### A6.2
ref 是标准答案，尺子（bins）必须由它唯一确定，gen 改变不能影响尺子。①丢弃超出样本：破坏密度归一化（分子变小分母 N 不变），更糟的是 gen 超出 ref 支撑域本是"分布不同"的最强证据，丢弃等于隐瞒差异——极端情况下两分布完全分离 L1 反被算成 0；且只有 gen 被单方面丢弃，不公平。②合并扩范围：bins 随 gen 波动导致结果不可复现、跨模型不可比；n_bins 不变而范围变大 → bin_width 变大 → 密度整体被稀释 → L1 被系统性低估；甚至反向激励"越发散 L1 越小"。归到边缘 bin 则让超出部分抬高边缘密度，如实计入差异。

### A6.3
上界 2。p_gen 与 p_ref 支撑集完全不重叠时，每个 r 处只有一个密度非零，∫|p_gen−p_ref|dr = ∫p_gen + ∫p_ref = 1+1 = 2。实测偏移 +0.5 时 L1=1.094，已接近上界的一半。

### A6.4
statistic 是 D = max|F_gen−F_ref|，回答"两组分布差多远"，取值 [0,1]，几乎不随样本量系统漂移；pvalue 回答"若两组同分布，观察到当前 D 的概率"，是假设检验量。n=500 万时任何微小数值差异都会把 pvalue 压到接近 0，同分布也永远"拒绝 H0"，无法当模型分数；且阶段 3/4 生成样本数不同（500 vs 2000），只有 D 跨样本量可比。

### A6.5
固定 x 处 F_n(x)=k/n 是二项比例 B(n,p)/n，标准误 √(p(1−p)/n) ≤ 1/(2√n)，故 ECDF 处处有 1/√n 量级抖动。DKW：P(sup|F_n−F| > ε) ≤ 2exp(−2n_eff ε²)，对半切 n_eff=n/4。代入 ε=0.01、要求误报率 <0.05：2exp(−2·(n/4)·10⁻⁴)<0.05 → n_eff>1.85 万 → 总 n>7.4 万。n=5000 时噪声地板约 1/√1250≈0.028（带常数的精确水平约 0.014），与阈值 0.01 同量级，再正确的实现也会"超线"；n=20 万时地板降到 ~0.0045，阈值之下立刻通过。Day 6 全库 1000 万点实测 D=0.00084，与 1/√2.5e6≈0.00063 同量级。

### A6.6
把 ref 分布想成单位质量的土堆，W1 是所有把土堆成 gen 形状的运输方案中 ∫∫|x−y|γ(x,y)dxdy 的最小值（质量×距离）。一维有闭式结论 W1 = ∫|F_ref(x)−F_gen(x)|dx，即两条 CDF 曲线之间夹的**总面积**（对比 KS 只取最大垂直高度）。等样本量离散算法：两组分别排序，第 k 小对第 k 小，W1 = mean(|sort(ref)−sort(gen)|)——不交叉配对即最优。所以 ref+0.5 时实测 W1 精确等于 0.5。

### A6.7
①窄峰错开：不重叠时两个密度各自积 1，L1=|1−0|+|0−1|=2，与错开 0.1 还是 100 无关（饱和，无法区分偏多偏少）；W1 每粒土都恰好搬 δ，故 W1=δ，线性精确、不饱和。②1% 质量搬到 100：两条 CDF 最大差距只有 0.01，故 KS=0.01，搬到 1000 仍是 0.01（KS 只问"差多少质量"不问"搬多远"）；W1=0.01×100=1，搬到 1000 则 W1=10。信道含义：深衰落是小概率但致命的事件，KS/L1 可能报"只差 1% 很好"，W1 会对"那 1% 的深衰落电平偏了多少 dB"明码标价。

### A6.8
mean=中心位置；std=离散程度（胖瘦）；skewness=左右对称性（正=右尾长，少数大值）；kurtosis=尾部重量（Fisher 口径，正=比正态厚尾）。Corazza 包络 r=R·S 非负、有下界 0 而上不封顶，呈右偏，skew>0；Rice×Lognormal 复合比正态更厚尾，excess kurtosis>0（可在 detail 里打印验证）。

### A6.9
Pearson 峰度 β₂=E[(X−μ)⁴]/σ⁴，正态分布 β₂=3；Fisher（超额峰度）γ₂=β₂−3，正态为 0、均匀分布约 −1.2、厚尾分布为正。两者只差常数 3。scipy.stats.kurtosis 默认 fisher=True。选 Fisher 是因为零点对齐正态，正负号直接读作"厚尾/薄尾"。相对误差分母 |ref|+1e-12 是防 ref 矩接近 0（对称分布 skew≈0、恒幅场景 mean 也可能近 0）时除零。

### A6.10
对半切是阴性对照，防假阳性（冤枉好模型：同分布却报差异）；加偏置是阳性对照（突变测试思想），防假阴性（尺子瞎了：分布真不同却报 0）；同种子复现是科学底线，防不可复现。+0.5 是纯平移，主要点亮 W1（线性精确）与 mean 相对误差；×1.2 是尺度变化，主要点亮 std。只注入一种可能恰好绕过另一类指标（如缩放分布 mean 偏移占比小，平移则 std 完全不变），两种一起保证四个指标都被至少一种突变点亮。

### A6.11
阶段 2 的指标在物理量上定义：LCR/AFD 门限是 dB 归一化电平、BER 链路需要真实信道增益、W1 的数值单位就是包络量纲（W1=0.5 读作"平均偏移 0.5"）。在 log 标准化域算出的距离没有直观物理意义，也无法和论文报告值直接对照。inverse_standardize 对两组用同一个全库常量，是双射且不引入不对称，不影响公平性。

### A6.12
5 倍是信噪比判据：基线是指标自身的统计噪声地板，2 倍以内完全可能是随机波动（约 2σ），10 倍又过严、逼测试用脱离实际的大偏移；5 倍意味着观测差异中绝大部分（≥80%）来自真实分布差。实测偏移后涨 343 倍，余量故意留很大防 CI 抖动误报。场景 3 整条链路（rng→置换→划分→纯函数指标）本应确定性地逐位相同，浮点近似只该出现在"有统计噪声"的对半切/加偏置场景；若这里也用容差，漏传 rng、误用全局 np.random 等非确定性 bug 就会被容差掩盖。

## Day 7 参考答案

### A7.1
时间结构只存在于序列内部。首尾拼接后，上一条末尾与下一条开头被当成时间上相邻的两点：①LCR——两条独立序列在拼接点附近相对门限的大小关系是随机的，约以 P(r>r_th)·P(r≤r_th) 的概率凭空制造一次"穿越"，序列越多假穿越越多，LCR 系统性偏高；②ACF——大滞后点会把本不相关的两条序列样本做配对，混入跨序列伪相关，拖慢 ACF 衰减。故 `_as_2d` 强制 (n_samples, length) 形状、沿 axis=1 计算。

### A7.2
L2 要评估的是"起伏的节奏/形状"，应不受整体功率缩放影响：用每条自己的 r_rms,i 归一门限后，把整条序列乘以常数完全不改变 LCR/AFD/ACF（形状不变性）。若用全库统一门限，低仰角序列全程在门下、高仰角全程在门上，测出来的是仰角功率差异而非节奏。整体功率/电平偏差由此正交地交给 Day 6 的 W1、mean/std 去扣分，两类指标不重复计分。

### A7.3
各条序列均值和能量不同（不同仰角），若直接在原始幅度上做集成 ACF，大功率序列主导平均，测的是功率加权混合。逐序列零均值化+除以自身零滞后能量后，每条贡献一条 R(0)=1 的归一化 ACF，等权平均才是"典型形状"。拼成一条算还会同时犯 A7.1 的拼接伪相关错误，并被序列边界污染大滞后。

### A7.4
长度 L 的线性自相关非零区间是 2L−1。DFT 逐点相乘对应**循环卷积**，长度只有 L 时滞后 k 与滞后 k−L 混叠：序列开头被当成结尾的时间邻居，大滞后点出现虚假相关（首尾统计特性偶然相似）。补零到 ≥2L−1（取 2 的幂加速 FFT）后两副本不重叠，得到线性相关。

### A7.5
有限样本的自相关估计本身有抖动：白噪声滞后 k≥1 的理论相关为 0，但样本估计标准差约 1/√n，n=1e5 时约 0.0032；前 50 个点取最大值，期望约为单点标准差的 2~3 倍 → 0.0095 完全正常，且随 n 以 1/√n 缩小。平滑序列是一阶 IIR 低通过程（模拟 0.3s 相关时间的阴影慢变），其理论 ACF 为 a^k = exp(−τ/τ_c)，τ=τ_c=0.3s 时恰为 e⁻¹≈0.3679；实测 0.360，偏差约 2%。

### A7.6
向下穿越条件：`(r[t] > r_th) & (r[t+1] <= r_th)`，对整段求和即穿越次数，除以总时长 (L−1)/fs 得次/秒。选向下穿衰落门限是因为它对应"进入衰落"事件：一次向下穿越开启一段衰落驻留，与 AFD（每次驻留多久）、深衰落发生频率直接对应；向上穿越是"恢复"事件，统计它在平稳过程中与向下穿越率相同（边界效应除外），但物理语义上向下穿越才是衰落的开始。

### A7.7
门限是包络**幅度**电平，而 dB 的幅度定义是 20log₁₀（功率才是 10log₁₀，功率∝幅度²）。反算线性比：ρ=10^(dB/20)。−10 dB → 10^(−0.5)≈0.316，即门限设在该序列 RMS 的 0.316 倍；+10 dB 则是 3.16 倍 RMS。

### A7.8
AFD = 低于门限的时间比例 ÷ 单位时间进入次数 = 每次衰落平均持续多少秒（总低于时长/总进入次数）。逐序列算比值再平均有两个问题：短序列在高门限可能零穿越→比值无定义/小分母爆炸；单次衰落的 AFD 抖动大，比值平均被这些噪声点放大。用全库聚合量 N_below/(fs·N_cross) 等价于期望驻留时长的总量估计，样本越多越稳，且与 LCR 共享同一次穿越计数（notes/09 要求二者来自同一批数据，定义自洽）。

### A7.9
穿越次数是稀有事件计数，近似泊松变量，其相对统计误差约 1/√N_cross。+10 dB 门限（3.16 倍 RMS）远高于典型包络，每条 1s 序列只有个位数穿越，5000 条聚合 N_cross 仍只有约万级，1/√万≈1% 量级，再叠加序列间仰角混合的异方差，实测 11~13% 合理。若生成样本只有 500 条，N_cross 小一个数量级、该点噪声可达 30%+，此时 10 dB 门限的 LCR/AFD 读数不能作为模型差异证据，应：报告置信区间、在 RMSE 中降权或剔除该点、或增加序列长度/条数后再评估。低门限（−10、−5 dB）穿越充足，5~6% 的对半误差才是可靠基线。

### A7.10
各门限 LCR/AFD 数值跨数量级（次/秒从几十到几千、AFD 从毫秒到几十毫秒），线性 RMSE 会被大值门限主导，相对 RMSE 让每个门限等权贡献"偏差百分比"。零穿越时 AFD 在数学上无定义（驻留次数为 0，"平均每次多久"不可除），记 0 会伪造"衰落从不持续/瞬时恢复"的假信号并污染相对误差分母；记 nan 是显式标记"该门限数据不足"，强迫调用方处理（降权/加样），与 BER=0 的平滑下限同理，都是不让"没观测到"冒充"观测到零"。

### A7.11
每条序列独立置换只改变点的时间顺序，任一时刻的幅值集合不变 → 边际 PDF、CDF、矩全部不变，故 Day 6 三个距离纹丝不动；但相邻点关系被彻底随机化：ACF 除 0 滞后外全部塌到接近 0（RMSE 0.354），独立同分布序列穿越门限的频率由相邻点联合概率决定、远高于有色序列（LCR 相对 RMSE 5.13），AFD 随之大变（0.82）。结论：L1 管"瞬时幅值分布对不对"，L2 管"时间动力学对不对"，L1 是必要非充分条件。论文中学长 CGAN 的 LCR RMSE 高达 0.58~0.88（明显弱项），而扩散模型对时序相关结构的建模能力通常更强，L2（尤其 LCR）因此是两模型最可能拉开差距、也最值得在答辩中展示的战场。

### A7.12
K=0（纯 Rayleigh）时直射分量 m=0，闭式公式中 I0(0)=1、exp(−K)=1、√(K+1)=1，退化为 N(ρ)=f_d·ρ·√(2π)·exp(−ρ²)，不含任何未知参数，可直接当"标准答案"做绝对锚定（实测最大误差 9.94%，与 Day 3 的 9.9% 互相印证，锁定了 threshold_stats 的计数口径）。完整 Corazza = Rice 快衰落 × Lognormal 慢阴影，阴影的 IIR 慢变调制使 LCR 没有简单闭式解，无法构造理论参照。各项物理含义：√(2π(K+1)) 为尺度因子；f_d 最大多普勒频移，决定包络起伏的时间速率；ρ 为相对本地 RMS 的归一化门限；exp(−K−(K+1)ρ²) 是 Rice 包络分布导出的指数项；I0(2ρ√(K(K+1))) 是直射分量对穿越概率的修正（零阶第一类修正贝塞尔函数）。
