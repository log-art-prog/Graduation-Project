## 1. 模型总览

Corazza 复合衰落模型：

$$r = R \cdot S$$

- **R（Rice 快衰落）**：多径信号干涉，毫秒级起伏。直射分量 m + 散射分量 σ_R·(z1 + j·z2)，包络 $R = \sqrt{(m + \sigma_R z_1)^2 + (\sigma_R z_2)^2}$。
- **S（Lognormal 慢阴影）**：遮挡导致的缓慢变化，百毫秒~秒级。$S = \exp(\mu + h \cdot \sigma \cdot z)$，h = ln10/20 桥接 dB 与奈培。
- **两层时间尺度叠加**：快起伏乘在慢包络上，是真实卫星信道的核心特征。

### 仰角参数化（Corazza 1994 Table I）

仰角 α ∈ [20°, 80°] 决定三个分布参数：
- K(α) = K₀ + K₁α + K₂α²（线性莱斯因子）
- μ(α) = μ₀ + μ₁α + μ₂α² + μ₃α³（ln S 均值，奈培）
- σ(α) = σ₀ + σ₁α（阴影标准差，dB）

## 3. 单位与勘误结论

### 单位裁决（Corazza & Vatalaro 1994 式(3)）

| 参数 | 单位 | 说明 |
|------|------|------|
| K | 线性（非 dB） | 直射功率 / 散射功率 |
| μ | 奈培（Np） | ln S 的均值 |
| σ | dB | 20·log₁₀(S) 的标准差 |

采样 S 时：$S = \exp(\mu + h \cdot \sigma \cdot z)$，h = ln10/20 ≈ 0.1151 把 σ 从 dB 转到奈培域。

### K₀ 勘误

- 学长论文表 3-1 印 K₀ = 2.371
- Corazza 原文 Table I 为 **K₀ = 2.731**
- 学长图 3-1 曲线像素提取对应 2.731，确认 2.371 为笔误
- 代码与图已按原文 2.731 实现

## 6. 实现关键决策

### 6.1 快衰落：频域 Jakes 谱滤波

白噪声 → FFT → 乘 √S_Jakes(f) → IFFT → 色噪声。

- 为什么乘 √S：功率谱 = 幅度²，要让输出功率谱 = S(f)，频域幅度乘 √S。
- 端点奇异：Jakes 谱在 ±f_d 处分母为 0，用 `np.maximum(1-(f/fd)², eps)` 正则。
- 归一化：最后强制零均值单位方差，保证与 Day 2 的 N(0,1) 可互换。

### 6.2 慢阴影：一阶 IIR 低通

$g[n] = (1-a) \cdot w[n] + a \cdot g[n-1]$，$a = e^{-1/(f_s \cdot \tau_c)}$。

- 负号来源：要求 $a^{f_s \tau_c} = e^{-1}$，取对数得 $\ln a = -1/(f_s \tau_c)$。
- a > 1 会指数发散，必须 < 1。

### 6.3 标准化常量全库统一

10000 条全部生成后，一次性算 mu_log/sigma_log，所有样本共用。
- 边生成边算会导致仰角间强度差异被抹掉，模型学不到物理规律。
- 推理时也用同一组常量反还原。

### 6.4 KS 检验加速

`corazza_cdf_theory` 用 `scipy.integrate.quad`（标量函数），逐样本调用极慢。
改为在样本范围内取 200 个网格点算理论 CDF，再 `np.interp` 插值回样本点。积分次数从 N 降到 200。

## 7. 已知局限

1. **循环卷积边界效应**：频域滤波法相当于循环卷积，序列首尾有绕回污染。自检时用"过采样截断"（生成 2n 取中间 n）缓解。
2. **均匀散射假设**：Jakes 谱假设反射体均匀分布在全向，实际环境可能非均匀。
3. **npz 无内存映射**：npz 是 zip 容器，无法 mmap；40MB 全量读入内存，未来超大数据集需改 .npy 裸格式。
4. **K₀ 勘误**：学长表 3-1 的 K₀=2.371 已按原文修正为 2.731，与学长数值有偏差，论文复现说明中需注明。
