## 1. 这个模型在毕设里扮演什么角色

CGAN（学长基线）和条件扩散模型（我们的工作）都不直接学物理公式，而是学**一批由 Corazza 模型生成的包络序列样本**的统计规律。所以 Corazza 模型是"裁判员的标准答案来源"：

- 训练阶段：它产出 10000 条 × 1000 点的包络序列当教材；
- 检验阶段：它的理论 PDF/CDF 曲线当标准答案，衡量生成模型学得像不像；
- 它只覆盖**窄带包络统计**，不含时延扩展、多普勒轨迹等，这一点论文 2.4.5 末尾也承认。

## 2. 模型总览：两个时间尺度相乘

```
r(t) = R(t) · S(t)
        ↑        ↑
   Rice 小尺度   Lognormal 阴影
   毫秒级快起伏   秒级慢包络
```

- **R(t) —— Rice（莱斯）分量**：接收信号 = 一条稳定直射径 + 大量随机散射径。快速抖动。
- **S(t) —— Lognormal（对数正态）阴影分量**：树木、建筑遮挡造成的慢变化。
- 两者相乘（不是相加），表示阴影同时压在直射和散射分量上——这是 Corazza 模型区别于 Loo 模型（阴影只压直射径、直射与散射相加）的关键。

物理图像：开着车在农村路边走，手机接收卫星信号——信号整体被路边树木成排地压低（S 慢变），压低的同时每个瞬间还在快速抖动（R 快变）。

## 3. Rice 分量 R 的数学定义

直射径幅度为 m、散射径两个正交高斯分量方差均为 σ₀² 时，包络 R 的概率密度：

```
                    r                ⎡  (r² + m²) ⎤
p_R(r) = ───── · exp ⎢− ─────────── ⎥ · I₀( r·m / σ₀² ),  r ≥ 0
          σ₀²              ⎣    2σ₀²    ⎦
```

（论文式 2-20，I₀ 是第一类零阶修正贝塞尔函数）

引入 **Rice 因子 K = m²/(2σ₀²)**（直射功率 / 散射功率）：

- K → 0：没有直射径，R 退化为瑞利分布（城市深遮挡）；
- K → ∞：几乎只有直射径，R 趋近常数（晴天高仰角）。

**采样方法（Day 2 代码，按 C&V 1994 式(5) 的归一化约定）**：

原文把 Rice 分量归一化到 **E[R²] = 1**（总功率为 1，阴影 S 承担全部增益变化），由原文式(5) 可得：

```
σ_R² = 1 / [2(K+1)]      （每个正交散射分量的方差）
m    = √( K / (K+1) )    （直射径幅度，m²/(2σ_R²) = K 可自行验证）
```

1. z1, z2 为两个独立 N(0, 1)；
2. R = √((m + σ_R·z1)² + (σ_R·z2)²)；
3. 检验：E[R²] = m² + 2σ_R² = K/(K+1) + 1/(K+1) = 1 ✓

（注意：不要用"σ₀=1 且 m=√(2K)"的非归一化写法，那样 E[R²]=K+1，会和原文式(7) 的理论 CDF 对不上。）

## 4. Lognormal 分量 S 的数学定义（单位已定案，见第 6 节）

原文 1994 式(3) 的精确形式：

```
                    1             ⎡  (ln S − μ)²  ⎤
p_S(S) = ───────────────── · exp ⎢− ──────────── ⎥ ,  S ≥ 0
          √(2π)·h·σ·S            ⎣   2(hσ)²      ⎦

其中  h = ln(10)/20 ≈ 0.11513
```

- **μ：奈培(Np)**，是 ln S 的均值；
- **σ：dB**，是 20log₁₀(S) 的标准差，原文原话称其为 "dB spread"；
- ln S 的标准差是 h·σ（奈培），不是 σ 本身——学长式(2-21) 漏写了 h。

**采样（两种等价写法，Day 2 用第一种）**：

```
z ~ N(0,1)
S = exp( μ + h·σ·z )                  # ln 域直接写

# 等价的全 dB 写法：
X_dB = 8.686·μ + σ·z                  # 20log10(S) ~ N(8.686μ, σ²)
S    = 10**( X_dB / 20 )              # S 是电压/包络，用 20log 不是 10log
```

数值量级（农村树阴影）：α=20° 时 μ=−0.735 Np（中位阴影 −6.38 dB）、σ=3.5 dB；
α=80° 时 μ≈0、σ=0.5 dB（近无阴影）。反证：若把 σ 当奈培，会推出 E[S]≈220 的荒谬值。

## 5. 复合分布：没有闭式解，靠数值积分

把 S 积分掉，得到 r = R·S 的 PDF（论文式 2-23）：

```
p_r(r) = ∫₀^∞  p_R(r/S) · p_S(S) / S  dS
```

CDF 借助 Marcum Q 函数 Q₁(a,b)（式 2-24/2-25）：

```
F_r(r) = ∫₀^∞  [ 1 − Q₁( √(2K), (r/S)·√(2(K+1)) ) ] · p_S(S) dS
```

（论文式 2-26）

**工程含义（也是论文用生成模型的动机之一）**：这个积分没有简洁的闭式答案，系统仿真里只能反复数值积分，很慢。如果生成模型能直接吐出服从该分布（还带时序结构）的序列，就绕开了积分。

**对我们代码的意义**：`scipy.integrate.quad` 数值积分版本就是 Day 2 的"裁判曲线"——i.i.d. 大样本的经验分布必须和它 KS < 0.01。

## 6. 仰角参数化（原文 Table I）：单位裁决与 K0 勘误 ✅

### 6.1 三个多项式（原文式(8)，α 单位为度，适用 20°~80°）

```
K(α) = K0 + K1·α + K2·α²
       K0 = 2.731,  K1 = −1.074×10⁻¹,  K2 = 2.774×10⁻³      # K 线性

μ(α) = μ0 + μ1·α + μ2·α² + μ3·α³
       μ0 = −2.331, μ1 = 1.142×10⁻¹,  μ2 = −1.939×10⁻³,  μ3 = 1.094×10⁻⁵   # μ 单位 Np

σ(α) = σ0 + σ1·α
       σ0 = 4.5,    σ1 = −0.05                                # σ 单位 dB
```

（农村树阴影环境，ESA L 频段测量拟合；城市/郊区另有系数，本课题只用农村）

### 6.3 ✅ 单位裁决（2026-09-19，证据链闭合，G1 关卡关闭）

**结论：K 线性、μ 奈培(Np)、σ dB——原文刻意混用，靠 h=ln10/20 桥接。**

证据：
1. **一手证据**：Corazza & Vatalaro 1994 原文式(3)（本地 `docs/references/corazza1994_land_mobile_satellite_channels.pdf` 第2页），
   原句："h=(ln10)/20, **μ and (hσ)² are the mean and the variance of the associated
   normal variate**; σ is usually referred to as the **'dB spread'**"。

3. **学长论文的两处不严谨**：表 3-1 未标单位；式(2-21) 漏 h；图 3-1 纵轴把 μ 也标成
   (dB) 属标注错误（图上画的 −0.735 等是奈培原值）。
4. 早先"三个量都是 dB"和"μ、σ 都是奈培"两种猜测均被原文否定。

**Day 2 不再做双路径 KS 单位试错**（单位已由一手法条定案）；KS 实验仍保留，但只验证

## 7. 论文的数据预处理规定（3.2.2 节，两模型必须共用）

1. **包络 log 域标准化**（论文式 3-8，ε = 1e-6）：

```
x = ( log(r + ε) − μ_log ) / σ_log
```

μ_log、σ_log 由**全训练集**统一估计一次，不能每个样本各算各的（否则各样本均值被强行拉平，仰角信息丢失）。

2. **仰角归一化**（论文式 3-7）：

```
α_norm = (α − 50) / 30        # 20°→−1, 80°→+1
```

3. 训练集规模：10000 样本，每样本 1000 点，仰角 20°~80° 均匀采样。

## 8. 论文的"时序黑箱"（重要认知）

论文给出的全部公式都是**单个时间点**的边缘分布；1000 点序列**点与点之间如何相关**（采样率、最大多普勒、阴影相关时间）完全没写。但他评价了 ACF/LCR，说明其代码中序列必然带时序结构。

我们的处理原则：

- 静态分布（Day 2）严格复现论文，可对论文图 3-2/3-3；
- 时序结构（Day 3）按经典理论自建：Rice 分量用 Jakes 多普勒谱整形高斯过程、阴影用低通过程，参数（f_s、f_d、阴影相关时间）明确标注为**本课题复现设定**并引用经典文献，不谎称复现学长数值；
- 用理论 ACF（J₀ 贝塞尔函数）和 Rice 理论 LCR 闭式公式自我验收。

详见 [PHASE1_TASKS.md](../plans/PHASE1_TASKS.md) Day 3。
