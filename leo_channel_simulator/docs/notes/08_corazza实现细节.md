## 1. 这个模型在毕设里扮演什么角色

CGAN（学长基线）和条件扩散模型（我们的工作）都不直接学物理公式，而是学**一批由 Corazza 模型生成的包络序列样本**的统计规律。所以 Corazza 模型是"裁判员的标准答案来源"：

- 训练阶段：它产出 10000 条 × 1000 点的包络序列当教材；
- 检验阶段：它的理论 PDF/CDF 曲线当标准答案，衡量生成模型学得像不像；
- 它只覆盖**窄带包络统计**，不含时延扩展、多普勒轨迹等，这一点论文 2.4.5 末尾也承认。

## 2. 模型总览：两个时间尺度相乘

```
r(t) = R(t) · S(t)
        ↑        ↑
   Rice 小尺度   Lognormal 阴影
   毫秒级快起伏   秒级慢包络
```

- **R(t) —— Rice（莱斯）分量**：接收信号 = 一条稳定直射径 + 大量随机散射径。快速抖动。
- **S(t) —— Lognormal（对数正态）阴影分量**：树木、建筑遮挡造成的慢变化。
- 两者相乘（不是相加），表示阴影同时压在直射和散射分量上——这是 Corazza 模型区别于 Loo 模型（阴影只压直射径、直射与散射相加）的关键。

物理图像：开着车在农村路边走，手机接收卫星信号——信号整体被路边树木成排地压低（S 慢变），压低的同时每个瞬间还在快速抖动（R 快变）。

## 3. Rice 分量 R 的数学定义

直射径幅度为 m、散射径两个正交高斯分量方差均为 σ₀² 时，包络 R 的概率密度：

```
                    r                ⎡  (r² + m²) ⎤
p_R(r) = ───── · exp ⎢− ─────────── ⎥ · I₀( r·m / σ₀² ),  r ≥ 0
          σ₀²              ⎣    2σ₀²    ⎦
```

（论文式 2-20，I₀ 是第一类零阶修正贝塞尔函数）

引入 **Rice 因子 K = m²/(2σ₀²)**（直射功率 / 散射功率）：

- K → 0：没有直射径，R 退化为瑞利分布（城市深遮挡）；
- K → ∞：几乎只有直射径，R 趋近常数（晴天高仰角）。

**采样方法（Day 2 代码）**：
1. x, y 为两个独立 N(0, σ₀²) 高斯数（先取 σ₀=1 归一化）；
2. 直射分量加在实轴：m = σ₀·√(2K)；
3. R = √((x+m)² + y²)。

## 4. Lognormal 分量 S 的数学定义

```
                    1            ⎡  (ln S − μ)² ⎤
p_S(S) = ──────────────── · exp ⎢− ─────────── ⎥ ,  S ≥ 0
          S·σ·√(2π)             ⎣      2σ²     ⎦
```

（论文式 2-21）

- μ、σ 是 **ln S 的均值和标准差**（若参数表给的是 dB 域，则换算关系见第 6 节）；
- 采样：z ~ N(0,1)，S = exp(μ + σ·z)。

---

## 5. 复合分布：没有闭式解，靠数值积分

把 S 积分掉，得到 r = R·S 的 PDF（论文式 2-23）：

```
p_r(r) = ∫₀^∞  p_R(r/S) · p_S(S) / S  dS
```

CDF 借助 Marcum Q 函数 Q₁(a,b)（式 2-24/2-25）：

```
F_r(r) = ∫₀^∞  [ 1 − Q₁( √(2K), (r/S)·√(2(K+1)) ) ] · p_S(S) dS
```

（论文式 2-26）

**工程含义（也是论文用生成模型的动机之一）**：这个积分没有简洁的闭式答案，系统仿真里只能反复数值积分，很慢。如果生成模型能直接吐出服从该分布（还带时序结构）的序列，就绕开了积分。

**对我们代码的意义**：`scipy.integrate.quad` 数值积分版本就是 Day 2 的"裁判曲线"——i.i.d. 大样本的经验分布必须和它 KS < 0.01。

## 6. 仰角参数化（表 3-1）与单位疑点 ⚠️

### 6.1 三个多项式（论文式 3-3 ~ 3-5，α 单位为度，适用 20°~80°）

```
K(α) = K0 + K1·α + K2·α²
       K0 = 2.371,  K1 = −1.074×10⁻¹,  K2 = 2.774×10⁻³

μ(α) = μ0 + μ1·α + μ2·α² + μ3·α³
       μ0 = −2.331, μ1 = 1.142×10⁻¹,  μ2 = −1.939×10⁻³,  μ3 = 1.094×10⁻⁵

σ(α) = σ0 + σ1·α
       σ0 = 4.5,    σ1 = −0.05
```

（农村环境，L 频段；城市/郊区另有系数，本课题只用农村）

### 6.2 代入几个仰角看看量级

| α | K(α) | μ(α) | σ(α) |
|---|------|------|------|
| 20° | 1.333 | −0.735 | 3.500 |
| 35° | 2.010 | −0.240 | 2.750 |
| 50° | 3.936 | −0.101 | 2.000 |
| 65° | 7.110 | −0.096 | 1.250 |
| 80° | 11.533 | −0.003 | 0.500 |

（2026-09-18 由 `scripts/day1_plot_params.py` 实跑确认，修正了此前手算的 μ 值）

物理趋势全部正确：仰角越高 → K 越大（直射越强）、σ 越小（阴影越稳定）。

### 6.3 ⚠️ 单位疑点（Day 1 必须核对，禁止凭感觉写死）

论文正文没有明确说 K、μ、σ 的单位。把上表与 Corazza & Vatalaro (1994) 农村参数的公认转述对照：

- K 从 1.33 到 11.5，**恰好在典型 LMS 信道 Rice 因子的 dB 范围（约 1~14 dB）**；若按线性值，K=1.33 意味着直射只比散射强 1.2 dB，20° 农村仰角偏低得不合理；
- σ 从 3.5 到 0.5，**正是常见转述中"阴影标准差 dB"的数值区间**；若按 ln（奈培）理解，3.5 奈培 ≈ 15 dB，农村低仰角偏大；
- μ 在 −0.74~0.22，理解成 dB 时阴影均值几乎不偏（合理），理解成奈培则偏 −6.4~1.9 dB。

**初步判断：三个量都是 dB 域参数**（多数二手实现即按此），此时采样换算：

```
K_lin = 10**(K_dB/10)
S = 10**( (μ_dB + σ_dB·z)/10 )          # 即阴影幅度
（若最终确认原文用 ln，则 S = exp(μ + σ·z)）
```

**Day 1 核对动作**：① 画出三参数随仰角曲线，与论文图 3-1 目视比对；② 查 Corazza & Vatalaro 1994 原文（IEEE Trans. Vehicular Technology, 43(2)）参数表确认单位；③ 结论写回本笔记，代码系数旁注明出处。在确认前，`corazza.py` 里同时保留 dB/ln 两种采样开关。

### 6.4 不得外推

多项式只是 20°~80° 的经验拟合，超出区间曲线会失真（如 σ 在 90° 变负），代码中加边界检查。

## 7. 论文的数据预处理规定（3.2.2 节，两模型必须共用）

1. **包络 log 域标准化**（论文式 3-8，ε = 1e-6）：

```
x = ( log(r + ε) − μ_log ) / σ_log
```

μ_log、σ_log 由**全训练集**统一估计一次，不能每个样本各算各的（否则各样本均值被强行拉平，仰角信息丢失）。

2. **仰角归一化**（论文式 3-7）：

```
α_norm = (α − 50) / 30        # 20°→−1, 80°→+1
```

3. 训练集规模：10000 样本，每样本 1000 点，仰角 20°~80° 均匀采样。

## 8. 论文的"时序黑箱"（重要认知）

论文给出的全部公式都是**单个时间点**的边缘分布；1000 点序列**点与点之间如何相关**（采样率、最大多普勒、阴影相关时间）完全没写。但他评价了 ACF/LCR，说明其代码中序列必然带时序结构。

我们的处理原则：

- 静态分布（Day 2）严格复现论文，可对论文图 3-2/3-3；
- 时序结构（Day 3）按经典理论自建：Rice 分量用 Jakes 多普勒谱整形高斯过程、阴影用低通过程，参数（f_s、f_d、阴影相关时间）明确标注为**本课题复现设定**并引用经典文献，不谎称复现学长数值；
- 用理论 ACF（J₀ 贝塞尔函数）和 Rice 理论 LCR 闭式公式自我验收。

详见 [PHASE1_TASKS.md](../plans/PHASE1_TASKS.md) Day 3。
