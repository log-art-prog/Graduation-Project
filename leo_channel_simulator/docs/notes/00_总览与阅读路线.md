# LEO 星地信道仿真器 — 代码学习笔记总览

> 配套代码目录：`leo_channel_simulator/`
> 建议按本笔记编号顺序阅读，每篇对应一个源码文件。

---

## 1. 项目是做什么的

基于卫星过顶轨道，仿真低轨卫星（LEO）到地面站之间的无线信道，输出：
仰角、斜距、多普勒频移、路径损耗、阴影衰落、小尺度衰落、接收功率、SNR 等。

## 2. 整体调用链

```
main.py                     程序入口：配置参数、调度、画图
  │
  ├─ tle_orbit.py           算轨道几何（仰角/斜距/多普勒）
  │
  └─ channel_model.py       信道核心：把下面三个模块串起来
        ├─ propagation.py   大尺度损耗（自由空间+大气+雨+云）
        ├─ environment.py   环境参数表 + 仰角→时延/K因子换算
        └─ fading.py        阴影衰落 + 瑞利/莱斯小尺度衰落 + 多径
  │
  └─ visualization.py       绘图与汇总表
```

## 3. 核心数据流（一句话理解）

> 轨道给出每个时刻的**仰角、斜距、速度** →
> 仰角决定**路径损耗、K因子、时延扩展** →
> 叠加**阴影衰落**得到总损耗 → 算**接收功率/SNR** →
> 再生成**小尺度快衰落**并统计衰落指标。

## 5. 关键物理直觉

- **仰角是全模型的主线变量**：仰角低 → 斜距大、斜穿大气层厚 → 损耗大；遮挡多 → K 因子小、时延扩展大。
- **过顶（仰角90°）时刻**：斜距最小、径向速度为 0 → 多普勒频移过零变号。
- **两类衰落要分清**：
  - 阴影衰落（大尺度、慢变、对数正态、空间相关）
  - 小尺度衰落（快变、瑞利/莱斯、由多径干涉引起）

## 6. 运行方式

```bash
cd leo_channel_simulator
python main.py
```
