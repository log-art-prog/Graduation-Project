## 1. 模块地图

| 模块 | 层次 | 入口函数 | 主指标 |
|---|---|---|---|
| `generative/metrics/distribution.py` | L1 静态分布 | `evaluate_distribution(r_ref, r_gen, n_bins)` | pdf_l1 / ks / wasserstein / 四矩相对误差 |
| `generative/metrics/temporal.py` | L2 时序特性 | `evaluate_temporal(r_ref, r_gen, fs, thresholds_db, n_lags)` | acf_rmse / lcr 相对RMSE / afd 相对RMSE |

| `generative/metrics/generalization.py` | 泛化 | `evaluate_generalization(...)` | kl / js / spearman |

## 2. 接口契约（阶段3/4 不得修改）

1. 所有距离函数签名 `(r_ref, r_gen, ...)`，参考在前；
2. 返回 dict 必含 `"value"` 键（标量或子指标 dict），子项明细在 `"detail"`；
3. L1/泛化接受任意形状（内部 flatten）；**L2/L3 必须保持 (n_samples, length) 二维，绝不跨序列展平**；
4. bins / 门限 / Eb/N0 网格显式传入或取模块级默认值（`DEFAULT_THRESHOLDS_DB`、`DEFAULT_EBN0_DB`），参考与生成共用；
5. 需要随机数的函数（ber）接收 `rng`；其余为纯函数，同输入逐位一致。

## 3. 关键实现约定（两模型公平性的技术细节）

| 约定 | 位置 | 理由 |
|---|---|---|
| 门限 r_th = 10^(dB/20)·r_rms，**每条序列自身 RMS** | temporal.py | L2 只管"起伏形状"，功率偏差留给 L1 |
| ACF 逐序列归一化再等权集成，FFT 补零到 ≥2L−1 | temporal.py | 避免循环卷积边界效应 |
| AFD = 全库 below_count /(fs·总穿越次数) | temporal.py | 聚合口径抑制短序列比值噪声 |
| 信道增益 g = r/√(E[r²]) 逐序列归一化 | ber.py | 同上哲学；判决 sign(y)=sign(y/g) 无需显式均衡 |
| 复噪声 E\|n\|²=1/(2γ)，γ=10^(EbN0/10) | ber.py | 使 g=1 时严格回到 ½erfc(√γ) |
| BER 平滑下限 max(BER, 1/n_bits) | ber.py | BER=0 时 log 有意义，两模型同口径 |
| KL/JS 直方图 +ε(1e-10) 平滑并重新归一化 | generalization.py | 防零概率 bin；注意 KL 绝对值随 eps 变，比较时用同一 eps |

## 4. 噪声地板速查（设验收阈值时查这里）

| 指标 | 对半切基线（5000 条/半） | 主要噪声来源 |
|---|---|---|
| pdf_l1 | 0.020（单仰角尖峰分布可达 0.03） | 直方图计数噪声 ~1/√n |
| ks | 0.0096 | DKW 1/√n |
| lcr / afd 相对RMSE | 5.7% / 5.8% | 高门限穿越计数 ~1/√N_cross |
| ber_rmse (log10) | 0.017 | 误码计数 + 平滑地板 |
| 高阶矩（skew/kurt） | 2~4% | 尾部样本稀少 |

**教训汇总**：阈值按样本量与分布形态校准；稀有事件指标（高门限 LCR、高 SNR BER）必须先看计数是否离开噪声地板。

## 5. 与学长报告值的对照口径

学长报告值（KS 均值 0.0362、LCR RMSE 0.7025、BER RMSE 0.1536、Spearman 0.9980）是**模型级**误差，
不能与我们对半切的**噪声地板**比较。阶段3/4 的验收口径是"与学长同量级"，指标实现本身以上述自测为准。
