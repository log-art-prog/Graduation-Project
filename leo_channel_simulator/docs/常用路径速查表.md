## 6. 最常用终端命令

### 进入项目

```powershell
cd c:\Users\龙贝\Desktop\leo_channel_simulator\leo_channel_simulator
```

### 查看当前位置

```powershell
Get-Location
```

### 确认 main.py 和 src 是否存在

```powershell
Test-Path .\main.py
Test-Path .\src
```

### 列出目录内容

```powershell
Get-ChildItem
```

简写：

```powershell
ls
```

查看新代码目录：

```powershell
ls generative
ls generative\data
ls docs
```

### 运行 Day 1 绘图脚本

```powershell
D:\anaconda\envs\leo_gen\python.exe scripts\day1_plot_params.py
```

### 验证 PyTorch 是否能用 GPU

```powershell
D:\anaconda\envs\leo_gen\python.exe -c "import torch; print(torch.__version__, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```

期望看到：

```text
2.11.0+cu128 True NVIDIA GeForce RTX 5060 Laptop GPU
```

### 清理 Python 缓存（遇到导入旧内容/空模块时可使用）

```powershell
Remove-Item -Recurse -Force generative\__pycache__, generative\data\__pycache__ -ErrorAction SilentlyContinue
```
