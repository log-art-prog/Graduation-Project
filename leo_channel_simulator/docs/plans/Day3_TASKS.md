## 0. 本日核心概念（动手前先看懂）

### 0.1 为什么 Day 2 的样本不能直接用

Day 2 的 `sample_corazza_iid` 生成的 100 万个点是**相互独立**的（i.i.d.），每个点和前一个毫无关系。但真实信道不是这样：你站在原地不动，接收信号这一秒和上一秒高度相关（卫星没飞多远、反射环境没变）。如果用 i.i.d. 样本训练生成模型，模型学到的是"白噪声"而非"真实信道时序"。

**Day 3 要做的事**：让 1000 个点连成的序列，在统计上像真实卫星信道——快衰落有 Jakes 多普勒相关结构（毫秒级相关）、阴影有低通慢变（百毫秒~秒级相关）。

### 0.2 Jakes 多普勒谱（Rice 分量的时序）

卫星和接收端相对运动 → 多径信号有**多普勒频移**。Jakes 1974 证明：均匀散射环境下，复基带信号的功率谱密度为：

```
S(f) ∝ 1 / sqrt(1 - (f/f_d)²),    |f| < f_d
```

- f_d = v/λ：最大多普勒频移（v=相对速度，λ=波长）
- 谱形状像一个"U"型碗：两端 f=±f_d 处发散（端点奇异），中间平
- 这个谱的逆傅里叶变换就是时域自相关函数 = **J₀(2π f_d τ)**（第一类零阶贝塞尔函数）

**关键无量纲量**：f_d / f_s（多普勒/采样率），决定归一化 ACF 形状。

### 0.3 阴影慢变（Lognormal 的时序）

阴影 S 不是每点独立抽的，而是**缓慢漂移**的。实现方法：在 ln 域做一个低通高斯过程（白噪声过滤掉高频成分），让相邻样本相关。

- 一阶 IIR 滤波器：g[n] = (1−a)·w[n] + a·g[n−1]，参数 a 控制相关时间
- 等效相关时间 τ_c ≈ −1/(f_s·ln(a))，目标 τ_c ≈ 0.3 s

### 0.4 LCR（电平通过率）自检理论

**LCR = 单位时间内信号向下穿过某门限的次数**。Rice 分布有闭式 LCR 公式：

```
N_R(r_th) = sqrt(2π(K+1)) · f_d · ρ · exp(−K − (K+1)ρ²) · I₀(2ρ·sqrt(K(K+1)))
```
其中 ρ = r_th / R_rms（门限/RMS幅度）。

这是时序相关性的"裁判曲线"——经验 LCR 对上理论公式，说明时序结构对了。
