## 这一阶段在毕设中的位置

```
阶段1 数据层 ✅ → 【阶段2 指标库】→ 阶段3 CGAN → 阶段4 扩散模型 → 阶段5 对比
                      ↑
            "先建尺子，再量东西"
            指标接口在本阶段冻结，阶段3/4全程不改
```

为什么指标库要在模型之前做：CGAN 和扩散模型的输出都要靠它打分。如果边训模型边写指标，很容易出现"指标为某模型量身定制"的公平性问题。先把尺子做好、校准好（双向自测），后面两个模型谁也别想改尺子。

## 核心设计原则（阶段2全程遵守）

1. **接口冻结**：所有指标函数签名在 Day 6 定稿，后续只加不删不改参数语义
2. **统一输入**：所有指标接收 `r_ref`（参考样本）和 `r_gen`（生成样本），形状为 `(n_samples, length)` 或 `(n_samples,)`，函数内部自动展平
3. **统一输出**：每个指标返回 `dict`，至少含 `value`（指标值）和 `detail`（子项明细），方便阶段5汇总
4. **rng 入参**：需要随机的地方（重采样、补比特）必须接收 `rng`，保证可复现
5. **bins/门限显式传入**：不硬编码，调用方统一指定，保证参考与生成用完全相同的 bins/门限

## Day 6：L1 静态分布指标

> 详细任务表见 [Day6_TASKS.md](Day6_TASKS.md)

**目标**：实现比较两组样本"某一瞬间幅值分布"的全部指标。

**指标清单**：
- PDF L1 距离（相同 bins 的归一化直方图逐 bin 差绝对值积分）
- CDF KS 距离（`scipy.stats.ks_2samp`）
- Wasserstein-1 距离（`scipy.stats.wasserstein_distance`）
- 矩统计：mean / std / skewness / kurtosis，报告相对误差

**验收**：
- 参考分布对半切，L1/KS/Wasserstein ≈ 0，矩相对误差 < 1%
- 给样本加偏移/缩放后，各指标按预期变大

## Day 7：L2 时序指标（ACF / LCR / AFD）

> 无细化任务表，按本节概要 + notes/09 第 3 节实现（已完成，见 Day7 工作日志）

**目标**：比较两组样本"随时间起伏的节奏"。

**指标清单**：
- ACF：包络归一化自相关，前 N 个滞后点的 RMSE
- LCR：多门限（ρ ∈ {-10,-5,0,5,10} dB）向下穿越率，报告各点值 + 整体 RMSE
- AFD：P(r<r_th) / LCR(r_th)，多门限报告

**验收**：
- 白噪声 ACF 近似 δ、平滑序列 ACF 展宽
- Rayleigh（K=0）序列 LCR 对 Rice 闭式公式误差 < 15%

## Day 8：L3 系统性能（QPSK BER）

> 无细化任务表，按本节概要 + notes/09 第 4 节实现（已完成，见 Day8_9 工作日志）

**目标**：把生成包络过一遍真实调制解调链路，算 BER 曲线。

**流程**：
1. 随机比特 → QPSK 映射
2. 信道：y = s·g + n，g = r/√(E[r²])
3. Eb/N0 = 0~34 dB，步长 2 dB
4. 判决 → 误码统计 → log10(BER) 域 RMSE

**验收**：
- 理想恒幅信道（g=1）下 BER 与 ½erfc(√γ) 理论曲线重合
- BER=0 时加平滑下限 max(BER, 1/总比特数)

## Day 9：泛化指标 + 全库双向自测

> 无细化任务表，按本节概要 + notes/09 第 5 节实现（已完成，见 Day8_9 工作日志）

**目标**：泛化指标 + 跑通全部指标的双向自测。

**泛化指标**：
- KL 散度（直方图 +ε 平滑）
- JS 散度（对称有界，主报告量）
- Spearman 秩相关（仰角 vs 生成包络均值）

**双向自测**：
1. Corazza 参考 vs Corazza 参考（同分布对半切）→ 全部指标 ≈ 0
2. 人为加偏置（偏移/缩放/打乱时序）→ 对应指标显著变大
3. 全部指标函数同种子两次结果一致

**验收**：双向自测脚本一键通过，输出自测报告。
