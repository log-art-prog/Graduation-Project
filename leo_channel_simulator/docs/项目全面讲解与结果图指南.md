## 二、仿真代码详细讲解

### 2.1 Corazza 参考模型（数据生成核心）

**文件**：`generative/data/corazza.py`

**数学模型**：Corazza & Vatalaro (1994) 复合衰落模型，包络 r = R × S：
- R：Rice 快衰落（直射分量 + 多径散射）
- S：Lognormal 慢阴影

**仰角参数化**（`corazza_params`）：
- K(α) = 2.731 - 0.1074α + 0.002774α² （线性莱斯因子）
- μ(α) = -2.331 + 0.1142α - 0.001939α² + 1.094e-5α³ （奈培，ln S 的均值）
- σ(α) = 4.5 - 0.05α （dB，20log10(S) 的标准差）

> 注意：学长表3-1 中 K0 印作 2.371 系抄录笔误，原文 Table I 为 2.731。本项目以原文为准。

**i.i.d. 采样**（`sample_corazza_iid`）：
1. 从仰角算出 (K, mu, sigma)
2. 采样 Rice 分量 R：复信号 Z = (m + s_R·z1) + j·(s_R·z2)，包络 R = |Z|
   - s_R = √(1/(2(K+1)))，m = √(K/(K+1))，由 K 和归一化条件 E[R²]=1 联立解出
3. 采样 Lognormal 阴影 S：ln S ~ N(mu, (h·sigma)²)，h = ln(10)/20 ≈ 0.1151（dB→奈培桥接）
4. 复合包络 r = R × S

**时序生成**（`generate_corazza_sequence`）：
1. 仰角→参数 (K, mu, sigma)
2. 两路独立 Jakes 色噪声（I/Q）：白噪声→FFT→乘√S_jakes(f)→IFFT→归一化
   - Jakes 谱：S(f) ∝ 1/√(1-(f/fd)²)，|f|<fd
   - ACF 理论值：R(τ) = J0(2π·fd·τ)
3. Rice 包络：R[n] = √((m+s_R·x[n])² + (s_R·y[n])²)
4. 一阶 IIR 低通阴影：g[n] = (1-a)·w[n] + a·g[n-1]，a = exp(-1/(fs·tau_c))
5. S[n] = exp(mu + h·sigma·g[n])
6. r[n] = R[n] × S[n]

**关键参数**：fs=1000Hz, fd=50Hz, tau_shadow=0.3s, length=1000

**注意事项**：
- R 和 S 共用同一个 rng 串行取数，确保两过程统计独立；切勿在内部另建 rng
- dB 和奈培单位转换必须用 h = ln(10)/20 桥接，不能直接用
- 理论 CDF 用数值积分（`corazza_cdf_theory`），换元 x=ln S 避免长尾不收敛

### 2.2 数据预处理（`transforms.py`）

**Log 标准化**（学长论文式3-7, 3-8）：
- 标准化：x = (log(r + eps) - mu_log) / sigma_log
- 逆变换：r = exp(x · sigma_log + mu_log) - eps
- eps = 1e-6（防 log(0)）

**仰角归一化**：
- α_norm = (α - 50) / 30，将 20°~80° 映射到 [-1, 1]

**关键注意**：mu_log / sigma_log 必须由**全训练集一次性估计并固定**，所有样本共用，不能每个 batch 重算。Day 4 已固化进数据集 npz 文件。

### 2.3 数据集构建（`dataset.py`）

**`build_dataset`** 流程：
1. 仰角均匀采样 [20, 80]°（10000 条）
2. 逐条生成原始包络（float64 精度）
3. **全部生成完后**一次性估计 mu_log/sigma_log（不能边生成边算）
4. 统一标准化，转 float32 存盘

产物 `corazza_train.npz` 含 6 个 key：x_std, alpha_norm, alpha_deg, mu_log, sigma_log, eps

### 2.4 CGAN 模型（`cgan.py`）

#### 生成器 SequenceNoiseFilterGenerator
- 输入：z ~ (B, 32, 1000) 高斯噪声 + 仰角条件常数通道 → 拼接为 (B, 33, 1000)
- 主体：4 层 Conv1d stride=1（通道 64→128→128→64, kernel=15, LeakyReLU）
- 输出头：Conv1d → (B, 1, 1000) 标准化 log 包络（无激活，WGAN 设定）
- 设计理念："时序噪声滤波"——把逐时刻白噪声滤波成具有时间相关性的包络序列

#### 判别器 LargeReceptiveFieldDiscriminator
- 输入：包络 (B, 1, L) + 仰角条件通道 → (B, 2, L)
- 5 层 Conv1d stride=2（1000→500→250→125→63→32, kernel=15）
- 感受野 = 14×(1+2+4+8+16)+1 = 435 点
- 末端全局平均池化 → Linear → critic 分数（非概率，WGAN 不用 sigmoid）
- 不用 BatchNorm（WGAN-GP 中 BatchNorm 会破坏梯度惩罚的逐样本独立性）

#### 训练框架
- WGAN-GP：损失 = E[D(fake)] - E[D(real)] + λ·GP（λ=10）
- TTUR：G 学习率 1e-4，D 学习率 3e-4
- Adam β=(0.0, 0.9)（WGAN 推荐设置，不用默认 0.999）
- n_critic=5（每训练 1 次 G 先训 5 次 D）
- EMA decay=0.999（采样一律用 EMA 权重）

#### 条件单调性正则（方案 R）
- 动机：WGAN-GP 损失只约束单个条件下的分布匹配，不约束条件间有序性，导致条件均值随机漂移（seed42/seed1234 双种子复现证实）
- 实现：同一批 z 跨条件复用，在 4 个等距仰角网格上计算包络均值，对所有逆序对 (lo<hi 但 m_lo>m_hi) 施加铰链惩罚 ReLU(margin - (m_hi - m_lo))
- 物理先验：仰角越高→阴影衰落越弱→包络均值越大

### 2.5 扩散模型

#### 调度表（`schedule.py`）
- linear：β 从 1e-4 线性增到 0.02（DDPM 原文设定）
- cosine：Nichol & Dhariwal 闭式，信息破坏更慢（消融备选）
- 前向扩散闭式：x_t = √ᾱ_t·x_0 + √(1-ᾱ_t)·ε

#### 去噪网络 ConditionalUNet1D（`unet1d.py`）
- 3 级下采样 1000→500→250→125（stride=2 Conv1d），通道 64→128→256
- 瓶颈：2 个残差块
- 上采样：F.interpolate（nearest）对齐长度 + 跳跃连接拼接（不用 ConvTranspose，因 1000 非 2 的幂）
- kernel=15（与 CGAN 同款大核，捕捉信道自相关）
- 时间步编码：正弦位置编码 → 2 层 MLP → 逐残差块**相加注入**
- 仰角条件：标量 → 嵌入 MLP → 每个残差块一组 FiLM (γ,β) **逐通道仿射调制**
  - h ← h·(1+γ) + β
- 稳定性：FiLM 投影层和输出头 zero-init（训练起点等价无条件模型且 ε̂≈0）

> **与 CGAN 条件注入的关键差异**：CGAN 用"单次常数通道拼接"（简单但全局），扩散用"逐残差块 FiLM 仿射"（精细但参数更多）。这是论文对比要点之一。

#### DDPM 训练（`ddpm.py` + `train_ddpm.py`）
- 训练目标：ε-prediction MSE（最简单，无对抗博弈）
  - t ~ U{0..T-1}，ε ~ N(0,I)
  - L = ‖ε − ε_θ(√ᾱ_t·x_0 + √(1-ᾱ_t)·ε, t, α)‖²
- 优化器：Adam lr=2e-4, β=(0.9, 0.999)（标准 DDPM，与 CGAN 的 WGAN 设置不同）
- batch=64, EMA=0.999, 30000 步
- 训练只做 1 次前向/步（CGAN 一步 6 次前向：n_critic+1），"同墙钟"口径由阶段 5 补报

#### DDPM 采样（`ddpm.py` p_step）
- 反向采样：x_{i-1} = 1/√α_i · (x_i − β_i/√(1-ᾱ_i)·ε̂) + √β_i·z
- **clip_x0 裁剪**：欠训练时大 t 处 ε̂ 失准，x̂₀ = (x − √(1-ᾱ)·ε̂)/√ᾱ 会放大上万倍。裁剪 x̂₀ 到 [-30, 30]（真实数据 [-16.7, 3.5]，门限保留全部真实尾部），再按前向闭式反推一致的 ε̂

#### DDIM 采样（`ddim.py`）
- 确定性跳步：取时间索引子序列（linspace 均匀跳步），η=0 完全确定
- x̂_0 = (x_i − √(1-ᾱ_i)·ε̂) / √ᾱ_i
- x_prev = √ᾱ_prev·x̂_0 + √(1-ᾱ_prev)·ε̂
- 同一套训练权重可直接走 20/50/100 步，用于速度-质量 Pareto 对比

### 2.6 采样接口

**CGAN 采样**（`sample.py`）：
- `load_generator(ckpt)` → 加载 checkpoint，用 EMA 权武装生成器 + 从冻结数据集读取标准化常量
- `generate_envelopes(G, meta, alpha_deg, n)` → 分批生成，逆标准化回物理包络

**扩散采样**（`sample_ddpm.py`）：
- `load_diffusion(ckpt)` → 重建调度表+去噪网络（EMA 权重）+ 读取标准化常量
- `generate_envelopes(diff, meta, alpha, n, sampler, ddim_steps)` → 支持 ddpm/ddim 两种采样器
- **物理域契约**：包络必须非负，exp(·)−eps 在极负尾部产生 -eps 量级伪负值，投影回 0

### 2.7 评估流程（`phase3_eval_cgan.py` / `phase4_eval_ddpm.py`）

两个评估脚本**完全同口径**：
1. 加载模型（EMA 权重），对 20°~80° 步长 10° 各生成 500 条包络
2. Corazza 参考**共用缓存** `results/phase3/ref_*.npz`（同种子同数组，保证指标差异不掺参考序列差异）
3. 调用三层指标库逐项打分：
   - L1 分布：pdf_l1, ks, wasserstein, moments
   - L2 时序：acf_rmse, lcr_rel, afd_rel
   - L3 性能：ber_rmse
   - 泛化：kl, js, spearman
4. 验收线：KS 全部 < 0.07；Spearman > 0.99
5. 产物：CSV 指标表 + 45° PDF/CDF 对比图

### 2.8 采样耗时基准（`phase4_benchmark_sampling.py`）

协议：
- 吞吐：每仰角 n=500, batch=64, 7 仰角（20..80）
- 延迟：单条 n=1（batch=1），45°，重复 5 次取中位数
- 计时：torch.cuda.synchronize() + perf_counter，仅纯生成（不含指标计算与模型加载）
- 预热：正式计时前各跑一次小批量

### 2.9 关键注意事项汇总

1. **标准化常量**：mu_log/sigma_log 必须全训练集一次性固定，不能逐 batch 重算
2. **EMA 权重**：采样/评估一律用 EMA 权重（非 raw 权重）
3. **WGAN-GP 不用 BatchNorm**：会破坏梯度惩罚的逐样本独立性
4. **clip_x0**：扩散采样必须裁剪 x̂₀，否则欠训练时数值爆炸导致 exp 溢出
5. **物理域非负**：扩散生成后需 `np.maximum(r, 0.0)` 投影伪负值
6. **参考序列缓存共用**：CGAN 和扩散的评估共用同一组 Corazza 参考序列，确保指标可比
7. **种子管理**：`seed_everything()` 固定 numpy+torch+cudnn，`make_rng()` 用于数据生成
8. **CGAN 结构性短板**：WGAN-GP 损失缺乏跨条件有序性约束，导致条件均值随机漂移（30°↔40°、50°↔60°），即使加入单调正则（方案R）仍有 30° 仰角 KS=0.13 失败。扩散模型无此问题
9. **DDIM 步数选择**：20 步即满足分布保真（KS<0.02），50 步起在 BER 指标上反超 CGAN，1000 步 DDPM 质量最优但延迟极高
10. **Git 仓库结构**：真正的 Git 根在最外层，内层 leo_channel_simulator/ 是代码子目录，切勿在内层 git init

### 3.3 如何判断指标是否合格

#### 验收线一览

| 指标 | 合格线 | 优秀线 | 说明 |
|------|--------|--------|------|
| **KS 距离** | < 0.07 | < 0.02 | CDF 最大差异，最核心的分布指标 |
| **PDF L1** | < 0.15 | < 0.05 | 概率密度积分差异 |
| **Wasserstein** | < 0.05 | < 0.015 | 推土机距离，对尾部偏移敏感 |
| **mean_rel** | < 0.08 | < 0.01 | 均值相对误差 |
| **std_rel** | < 0.08 | < 0.01 | 标准差相对误差 |
| **ACF RMSE** | < 0.10 | < 0.02 | 自相关函数前50滞后点RMSE |
| **LCR rel** | < 0.35 | < 0.10 | 多门限电平穿越率相对RMSE |
| **AFD rel** | < 1.0 | < 0.15 | 多门限平均衰落时长相对RMSE（高门限无穿越时为nan，正常） |
| **BER RMSE** | < 0.15 | < 0.03 | log10域BER曲线RMSE |
| **Spearman** | > 0.99 | > 0.999 | 仰角→均值单调性 |
| **KL** | < 0.02 | < 0.001 | KL散度 |
| **JS** | < 0.005 | < 0.0001 | JS散度 |

### 3.4 看图要点

#### PDF/CDF 对比图（如 `phase3_cgan_pdf_cdf_45deg.png`）
- 左图 PDF：两组直方图应高度重叠，错位越大分布偏差越大
- 右图 CDF：两条曲线应紧贴，最大垂直间距即 KS 距离
- 生成分布若整体右移：均值偏高；若更宽：方差偏大；若尾部更长：极端衰落过度生成

#### 训练曲线
- CGAN（`train_curves.png`）：三面板 d_loss/g_loss/W_dist
  - d_loss 应稳定在低值（判别器略占优但不崩溃）
  - g_loss 波动正常（WGAN 特性）
  - W_dist 应收敛到稳定值（非0，表示到达均衡）
- DDPM（`train_curve.png`）：单条 ε-MSE
  - 应平滑单调下降，无剧烈震荡
  - 对比 CGAN：无对抗博弈，训练稳定性显著更优

#### 诊断图（如 `phase3_diag_20deg_*.png`）
- dist 系列：看 20° 仰角下生成 vs 参考的分布差异
- meancurve 系列：看仰角-均值曲线是否单调递增
  - CGAN 常见问题：相邻仰角均值交错（30°↔40°、50°↔60°），曲线出现波浪形
  - 扩散模型：曲线平滑单调

## 四、要点总结

### 4.1 项目四阶段闭环

| 阶段 | 内容 | 产物 | 状态 |
|------|------|------|------|
| Phase1 | Corazza 参考模型数据管线 | 10000×1000 冻结数据集 + 理论验证 | ✅ 完成 |
| Phase2 | 三层评价指标库 | L1分布/L2时序/L3系统+泛化指标 | ✅ 完成 |
| Phase3 | CGAN 基线复现 | WGAN-GP+FiLM+EMA，mono7训练，6/7仰角通过 | ✅ 完成（30°结构性短板） |
| Phase4 | 条件扩散模型 | DDPM+DDIM+1D U-Net+FiLM，全配置通过验收 | ✅ 完成 |

### 4.2 核心结论

1. **扩散模型质量全面优于 CGAN**：DDIM-20 即 KS=0.014（CGAN 最优 0.053），DDPM-1000 达 KS=0.003
2. **CGAN 存在结构性短板**：WGAN-GP 损失缺乏跨条件有序性约束，30°仰角 KS=0.13 失败，即使加入单调正则也无法根治
3. **扩散模型训练更稳定**：ε-MSE 单调下降，无对抗博弈的震荡问题
4. **成本-质量 trade-off**：DDIM-20 是甜点配置（20步即满足分布保真），DDPM-1000 质量最优但延迟约54倍于CGAN
5. **条件注入机制差异**：CGAN 用常数通道拼接（全局），扩散用逐残差块 FiLM 仿射（精细），后者在条件泛化上表现更好
