## 今日踩坑（按发现顺序）

1. **`np.saves` 打错**：应为 `np.savez`，numpy 没有 saves 函数，AttributeError。
2. **mkdir 没有调用**：把 `parents=True`、`exist_ok=True` 赋值给了两个变量，目录根本没创建。正确写法 `out_dir.mkdir(parents=True, exist_ok=True)`。
3. **key 名拼写错误**：`d["x_xtd"]` 应为 `d["x_std"]`，KeyError。
4. **`raise NotImplementedError` 残留**：填完代码后没删，`__init__` 每次初始化都崩。教训：TODO 骨架填完后要整体清一遍。
5. **异种子比较写错对象**：`d1` vs `d2`（都是 seed=42）写成异种子比较，diff 永远 False。应为 d1 vs d3。
6. **`torch.from_numpy` 不接受标量**：`self.alpha[idx]` 是 0 维 numpy 标量，必须先 `float()` 再 `torch.tensor(...)`；x 是一维数组才能用 from_numpy。
7. **meta.json 静默缺失（最有价值的坑）**：npz 已存在时验证脚本走"直接加载"分支绕过 save_dataset，meta.json 没生成但脚本照样全绿——G4"元数据齐全"实际没达标。**教训：自检脚本必须把验收表每一项都变成强制断言，不能依赖人工记忆。** 对策：加载分支补 `assert meta_path.exists()`。
8. **终端 cwd 与包位置不一致**：在项目外层目录跑 `python -c` 导致 `ModuleNotFoundError: No module named 'generative'`，先 cd 到内层再跑。
