## 三、踩过的坑（给以后看）

1. **ACF RMSE 压不到 0.02 以下**：序列长度 n=50000 时 RMSE=0.0279。原因：频域滤波法本质是循环卷积，序列首尾互相干扰。解决：增大到 n=100000 + 过采样截断（生成 2n 点取中间 n 点），RMSE 降到 0.0048。
2. **numpy 版本不兼容**：`np.trapz` 在 numpy 1.24+ 被移除，改名 `np.trapezoid`。报 AttributeError。
3. **导入路径错误**：`from .utils.seed import make_rng` 报 ModuleNotFoundError。原因：相对导入 `.utils` 指向 `generative.data.utils`，但实际在 `generative.utils`。改用绝对导入 `from generative.utils.seed import make_rng`。
4. **matplotlib 中文字体缺失**：未配置 `plt.rcParams["font.sans-serif"]` 时中文显示为白色方框（豆腐块）。解决：加 `["Microsoft YaHei", "SimHei"]` + `axes.unicode_minus = False`。
5. **ax.plot() 无 xlabel/ylabel 参数**：`xlabel`/`ylabel` 是 `ax.set_xlabel()`/`ax.set_ylabel()` 的参数，不是 `ax.plot()` 的。`ax.plot()` 只接受 `label=`（图例标签）。
6. **参数顺序写反**：`colored_gaussian_jakes(n, fd, fs, rng)` 把 fs 和 fd 传反了，导致 fd=1000 远超 fs/2，Jakes 谱完全混叠。函数签名是 `(n, fs, fd, rng)`。
